    强化学习 - 无模型预测的蒙特卡洛和时序差分 ¶

    约 2648 个字 1 张图片 预计阅读时间 9 分钟

    本篇为强化学习系列第 3 篇：无模型预测的蒙特卡洛和时序差分

    承接上一篇的动态规划：DP 依赖完整 MDP 转移模型 \(p(s',r|s,a)\)，通过期望精确求解贝尔曼方程；而无模型方法 (model-free，不需要模型，无论有没有模型都可以 )不再需要转移概率，直接和环境交互收集轨迹样本，用采样来估计价值函数

    前置回顾 ¶

    DP 的更新依赖转移分布求期望： $$ V_\pi(s) = \sum_a \pi(a|s)\sum_{s',r} p(s',r|s,a)\big[r+\gamma V_\pi(s')\big] $$

    这里必须知道转移概率 \(p\)。但现实中大量环境无法给出转移概率，只能通过交互得到回合轨迹： $$ S_0,A_0,R_1,S_1,A_1,R_2,\dots,S_T $$

    0. 从有模型预测到无模型预测 ¶

    • 预测问题：给定策略 \(\pi\)，估计状态价值函数 $$ V_\pi(s)=\mathbb{E}_\pi\left[G_t\mid S_t=s\right] $$

    • 有模型预测：DP 中通过贝尔曼期望方程迭代计算 $$ V_{k+1}(s)=\sum_a\pi(a|s)\sum_{s',r}p(s',r|s,a)\left[r+\gamma V_k(s')\right] $$

      它需要知道完整的 \(p(s',r|s,a)\)，并且每轮要遍历全部状态

    • 无模型预测：不再要求知道模型，而是从经验样本中估计价值：

      \[ \text{期望} \quad \mathbb{E}_\pi[G_t\mid S_t=s] \quad \Longleftrightarrow \quad \text{样本平均} \quad \frac{1}{N(s)}\sum_{i=1}^{N(s)}G_t^{(i)} \]

    无模型预测仅介绍两个方法：

    • 蒙特卡洛：采样完整 episode，用实际回报 \(G_t\) 估计 \(V_\pi(s)\)；
    • 时序差分：每走一步就利用奖励和下一状态的价值估计进行更新，即自举 (bootstrapping)

    1. 蒙特卡罗预测 (Monte Carlo, MC) ¶

    • 核心思想：蒙特卡罗直接利用 完整回合 (episode) 结束后的采样回报来估计价值

      • 本质：用完整回合采样的回报均值来估计价值，用样本均值来逼近期望。没有自举 (bootstrapping)，不使用下一步状态的价值估计
      • 大数定律：当采样回合数目足够大，同一个状态 \(s\) 观测到的回报样本的算术平均，会收敛到该状态价值的真实期望 \(V(s) \rightarrow V_\pi(s)\)

    • 类型：

      • 一条轨迹里同一个状态 \(s\) 可能多次出现：\(S_{t_1}=s,\ S_{t_2}=s,\dots\)，所以根据对状态 \(s\) 的采样处理分为两类
      • 首次访问 MC：一个回合内，只取第一次到达 \(s\) 的回报 \(G_{t_1}\) 加入均值统计，同一回合后续再次访问 \(s\) 全部忽略
        • 无偏估计，样本数量更少，样本方差更大
      • 每次访问 MC：一个回合内，每一次访问 \(s\)，都把对应的回报 \(G_t\) 加入均值统计。
        • 估计量有偏 ( 同一条轨迹里样本之间有相关性 )，样本利用率更高，方差更小

    • 增量更新形式

      • 不用存储全部历史回报，不需要维护一张总回报累加表，每拿到一个回报样本就在线更新价值：

        \[ V(s) \leftarrow V(s) + \alpha \big[G_t - V(s)\big] \]

        其中 \(\alpha\) 是步长，\(\alpha= \frac{1}{N(s)}\) 时等价于算术平均，\(N(s)\) 是状态 \(s\) 被统计的次数

      • 意义：\(G_t\) 是本次采样轨迹里，从时刻 t 访问状态 s 之后，实际得到的完整折扣回报，\(V(s)\) 是状态 s 当前的价值估计值，相减就是更新误差，也就是 实际观测到的回报 减去 旧的价值估计。\(\alpha\) 是更新步长 / 学习率，控制这一次样本对价值更新的强弱

    • MC 预测流程 ( 首次访问 )

      • 初始化价值表 \(V(s)\)，维护每个状态 \(s\) 的访问计数 \(N(s)=0\)
      • 按照策略 \(\pi\) 采样得到一条完整回合轨迹
      • 反向遍历这条轨迹，计算每个时刻对应的回报 \(G_t\)
      • 标记本回合已经访问过的状态集合；遇到 \(S_t=s\) 且 \(s\) 未标记：
        • \(N(s) \mathrel{+}=1\)
        • \(V(s) \mathrel{+}= \dfrac{1}{N(s)}\big(G_t - V(s)\big)\)
        • 标记 \(s\)，本回合不再统计
      • 重复采样大量回合，直到 \(V(s)\) 收敛到 \(V_\pi(s)\)

    • MC 的优缺点

      • 优点：

        1. 无模型，不需要转移概率 \(p\)，只需要和环境交互采样轨迹
        2. 对每个状态的估计可以独立，不需要遍历所有状态，只更新轨迹里实际走到的状态
        3. 无偏估计，首次访问 MC 是 \(V_\pi\) 的无偏估计

      • 缺点：

        1. 必须等到回合终止，才能反向计算整条轨迹每一个时刻的回报 \(G_t\)，只能用于回合式任务 (episodic)，不能用于持续型任务 (continuing)
        2. 方差大，回报 \(G_t\) 依赖后面一长串随机动作、随机奖励，采样噪声高
        3. 学习慢，每一步的影响要等到回合终止才回传

    2. 时序差分预测 (Temporal Difference, TD) ¶

    • 核心思想： TD 使用 自举(bootstrapping)：通过自身的估计值去更新当前的估计值。不需要等回合结束，每次直接用下一步的价值估计值来更新

    • 自举 (bootstrapping)：

      • 自举：通过重复使用自身的估计值来更新模型参数。强化学习中指的是，利用当前的价值估计来更新价值函数

      • 特点：

        • 偏差大：价值估计不准确，就会为自举引入误差
        • 方差小：TD 的更新基于一步或几步，不需要等整个回合结束，受随机性影响较小
        • 通常自举方法收敛速度更快

    • 价值更新公式： 用当前获得的奖励加上下一个状态的价值估计来作为在当前状态会获得的回报 $$ V(S_t) \leftarrow V(S_t) + \alpha \big[ r_{t+1} + \gamma V(S_{t+1}) - V(S_t) \big] $$

      • 可以用 \(r_{t+1} + \gamma V(S_{t+1})\) 来代替 \(G_t\) 的原因是 $$ G_t = r_{t+1} + \gamma \big(r_{t+2} + \gamma r_{t+3}+\dots\big) \ = r_{t+1} + \gamma V_\pi(S_{t+1}) \ \approx r_{t+1} + \gamma V(S_{t+1}) $$

      • TD 目标 (TD Target)：\(r_{t+1} + \gamma V(S_{t+1})\)。由于 TD 目标包含了最新的环境反馈 \(r_{t+1}\)，因此被认为比 \(V(s_t)\) 更接近真实值，常被作为价值函数拟合的目标

      • TD 误差 (TD Error)：\(r_{t+1} + \gamma V(S_{t+1}) - V(S_t)\)，可以记为 \(\delta_t\)，用作强化学习中的 loss

    2.1 TD(0)¶

    TD(0) 是最简单的 TD 预测算法，单步 TD

    • 更新公式： $$ V(S_t) \leftarrow V(S_t) + \alpha \big[ r_{t+1} + \gamma V(S_{t+1}) - V(S_t) \big] = V(S_t) + \alpha \delta_t $$

    • 特点：

      • 每走一步就更新，不需要等回合结束
      • 可以用于回合式任务，也可以适配持续型任务

    2.2 n-step TD¶

    TD(0) 只看往后 1 步，MC 看往后直到回合结束 ( 无穷步 )，n-step TD 是中间的一般形式

    • 更新公式： $$ V(S_t) \leftarrow V(S_t) + \alpha \big[ G_{t:t+n} - V(S_t) \big] $$

      n-step 回报：n 步的折扣回报 + 第 (t+n) 步的价值 $$ G_{t:t+n} = r_{t+1}+\gamma r_{t+2}+\dots+\gamma^{n-1}r_{t+n} + \gamma^n V(S_{t+n}) $$

    • 特点：

      • \(n=1\)：退化为 TD(0)

      • \(n\to\infty\)：退化为 MC

      • \(n\) 小：自举多、偏差高、方差低

      • \(n\) 大：自举少、偏差低、方差高

    2.3 TD(\(\lambda\))¶

    TD(\(\lambda\)) 引入 \(\lambda\) 作为权重，在 TD(0) 和 MC 之间进行平衡，不再像 n-step TD 那样只取某一个固定步数，而是把所有可能的 n-step 回报按 \(\lambda\) 的幂次加权平均

    • 更新公式： $$ V(s_t) \leftarrow V(s_t) + \alpha \big[G_t^\lambda - V(s_t)\big] $$

      其中，\(G_t^\lambda\) 是在时间步 \(t\) 的 \(\lambda\)回报，即综合考虑多个步数的回报，以 \(\lambda\) 为权重的加权和 $$ G_t^\lambda = (1-\lambda) \sum_{n=1}^{T-t-1}G_{t:t+n} + \lambda^{T-t-1}G_t $$

      其中：

      • \(T\) 是 episode 终止时间步，\(T\) 限制了回报的计算范围，使其不能延伸至无穷远
      • \(G_{t:t+n}\) 是 n-step TD 回报，从时间步 \(t\) 开始经过 n 步的回报： $$ G_{t:t+n} = r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1}r_{t+n} + \gamma^n V(S_{t+n}) $$
      • \(G_t\) 是从 时间步 \(t\) 到 episode 结束的实际回报 $$ G_t = r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{T-t-1}r_T $$

    • 特点：

      • \(\lambda = 0\)：\(G_t^0 = G_{t:t+1} = r_{t+1}+\gamma V(S_{t+1})\)，退化为 TD(0)
      • \(\lambda = 1\)：\(G_t^1 = G_t\)，退化为 MC，完全不使用自举
      • \(\lambda\) 越小，短期 n-step 回报权重越大，自举越强、偏差大、方差小
      • \(\lambda\) 越大，长程回报权重越大，越接近 MC，偏差小、方差大

    3. DP / MC / 穷举搜索 / TD 对比 ¶

    穷举搜索：在已知模型下，枚举所有可能的动作序列（或所有确定性策略），逐一精确计算其回报，直接选出最优者。它不做采样、不做自举，也不维护可复用的价值函数迭代

    蒙特卡洛 TD DP 穷举搜索
    是否依赖环境模型 否，只需能采样 episode 否，只需能采样单步转移 是，需要完整 \(p(s',r\|s,a)\) 是，需要完整模型来枚举和计算回报
    方差 大 ( 多个步骤使回报 \(G_t\) 累积随机性大 ) 小 ( 单步奖励加自举，随机性影响小 ) 小 ( 模型精确时为 0) 无 ( 精确枚举计算，不采样 )
    偏差 无偏估计 ( 大数定律 ) 有偏估计 ( 自举用估计值代替真实值 ) 无偏估计 无偏估计
    计算复杂度 中 低 高 非常高
    更新方式 回合结束后基于完整回报 在线更新，每时间步更新 递归式更新 穷举后更新
    目标 估计 \(V_\pi / Q_\pi\)，可扩展为控制 估计 \(V_\pi / Q_\pi\)，可扩展为控制 求解贝尔曼方程，得到 \(V_\pi / V_*\) 或 \(Q_\pi / Q_*\) 直接找出最优动作序列或最优策略
    学习速度 较慢 通常较快 中等 极慢，规模稍大就不可行
    适用场景 能完整观测回合终止，回合短 \(episodic / continuing\) 任务，模型未知，需在线更新 已知模型的有限离散 MDP，状态动作空间较小 极小规模，可穷举
    主要优点 无偏估计，无环境模型依赖 收敛快，方差小，实时更新 精确性高 易于实施
    主要缺点 方差大，更新慢 有偏估计 依赖环境模型 指数爆炸，复杂度过高
