    强化学习 - PPO 的实现 ¶

    约 5238 个字 992 行代码 预计阅读时间 30 分钟

    本篇为强化学习系列 番外篇：PPO 的实现

    承接 TRPO 与 PPO；在许多场景中，PPO 仍然是强化学习的主力算法：它实现相对直接、样本效率与稳定性之间比较平衡，也足够容易扩展到并行环境和复杂动作空间。

    PPO 的损失函数只有一行，但“PPO 能工作”在很大程度上依赖论文正文中几乎不提的实现细节。Engstrom 等人的系统性消融表明：有 Clip 但缺少关键工程细节的 PPO，往往不如有工程细节但使用朴素惩罚的版本

    你可以把它看作是对前文 TRPO/PPO 理论的落地补充：既关心“为什么这样写”，也关心“实际写的时候要注意什么”

    0. 前置回顾：¶

    PPO-Clip 总损失公式：

    \[ L^{CLIP+V+S}=\mathbb{E}\left[ \min\left( r_t A_t,\; \mathrm{clip}(r_t,1-\epsilon,1+\epsilon)A_t \right) - c_v \mathcal{L}_t^{VF}(\theta) + c_s \cdot S[\pi_\theta(\cdot|s_t)] \right] \]

    其中

    \[r_t=\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}\]
    • \(\epsilon\)：clip 系数，通常为 0.2
    • \(c_v\)：价值损失权重，通常为 0.5
    • \(c_s\)：熵正则系数，通常为 0.01

      注意符号：熵是加项，最大化熵等价于鼓励探索；代码里 loss 是最小化，因此 loss 里是减项

    GAE 广义优势估计 :

    \[A_t^{GAE(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l \delta_{t+l},\quad \delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\]
    • \(\lambda=0\)：单步 TD 误差
    • \(\lambda=1\)：蒙特卡洛回报价值
    • 常用 \(\lambda=0.95,\gamma=0.99\)

    1. PPO 核心实现要点总览 ¶

    下面所有代码块都会绑定对应的实现要点，一一对应：

    1. Rollout 缓冲区 + GAE 优势计算：缓冲区存储交互轨迹，逆序递推 GAE；兼容多 env 维度，方便后续并行扩展
    2. Actor-Critic 共享网络：同时支持离散 Categorical、连续高斯 Normal 动作分布，策略头 + 价值头共享特征提取
    3. On-Policy 数据收集：on-policy 算法必须使用旧策略采集轨迹；支持观测 RunningMeanStd 归一化
    4. 优势归一化：本实现是整批 rollout 归一化（和 minibatch 归一化是两种主流方案，SB3 原版风格），消除奖励尺度影响
    5. 多 Epoch 复用数据 + KL 早停：同一批轨迹多次训练提升样本利用率；KL 超过阈值立刻终止本轮 epoch，防止策略漂移过大
    6. 价值裁剪（可选）：SB3 风格价值裁剪，限制 critic 单次更新的跳动幅度
    7. 梯度全局裁剪：约束参数梯度二范数，防止梯度爆炸
    8. 调度器支持：学习率、clip 范围支持可调用函数，实现线性退火
    9. 熵正则：熵损失加入总 loss，鼓励策略保持探索性
    10. 保存与加载：同时保存网络、优化器、观测归一化统计量，支持断点续训

    2. 工具类观测归一化RunningMeanStd ¶

    # ==================== 1. 在线观测归一化 ====================
class RunningMeanStd:
    """
    维护运行均值和方差，用于对观测做白化。
    只在训练时更新统计量；评估/推理时固定使用训练得到的统计量。

    实现要点：
    - 使用并行算法（Chan et al.）增量合并批统计量，避免保存全部历史观测；
    - count 初始化为 epsilon 而非 0，防止早期除零，并让初始均值/方差平滑过渡；
    - update 支持 batch 维度，便于 rollout 结束后按整批观测更新；
    - 多环境并行时可将 x 展平为 (num_env * rollout_steps, obs_dim) 后统一更新。
    """
    def __init__(self, shape: Tuple[int, ...], epsilon: float = 1e-4):
        # 运行均值，形状与单条观测一致
        self.mean = np.zeros(shape, dtype=np.float32)
        # 运行方差，初始为 1，避免归一化时除零
        self.var = np.ones(shape, dtype=np.float32)
        # 有效样本计数，初始为 epsilon 防止除零
        self.count = epsilon

    def update(self, x: np.ndarray):
         """x 形状: (batch, obs_dim)"""
        # 当前 batch 的均值、方差和样本数
        batch_mean = np.mean(x, axis=0)
        batch_var = np.var(x, axis=0)
        batch_count = x.shape[0]
        # 将当前 batch 统计量与历史运行统计量合并
        self._update_from_moments(batch_mean, batch_var, batch_count)

    def _update_from_moments(self, batch_mean, batch_var, batch_count):
        # 合并两组统计量：历史统计量 + 当前 batch 统计量
        delta = batch_mean - self.mean
        total_count = self.count + batch_count
        # 更新均值：按样本数加权
        new_mean = self.mean + delta * batch_count / total_count
        # 更新方差：使用并行方差合并公式
        # m_a: 历史部分的平方偏差和；m_b: 当前 batch 的平方偏差和
        m_a = self.var * self.count
        m_b = batch_var * batch_count
        # 合并后的平方偏差和，额外加入两组均值差异带来的项
        m_2 = m_a + m_b + np.square(delta) * self.count * batch_count / total_count
        new_var = m_2 / total_count # 合并后的方差
        new_count = total_count     # 更新总样本数
         # 写回运行统计量
        self.mean, self.var, self.count = new_mean, new_var, new_count

    3. Rollout Buffer¶

    • 实现要点：
      1. 数组预留 (T, n_envs, ...) 维度，天然支持多环境并行扩展，当前单环境也兼容
      2. compute_returns_and_advantages：逆序循环实现 GAE，用1-done掩码截断 episode，终止状态之后不传播价值
      3. _flatten：把(T, n_envs, ...)展平为(T*n_envs, ...)，方便 minibatch 采样
      4. get生成器：打乱索引，迭代输出 mini-batch，训练阶段取用
      5. 缓冲区同时缓存old_log_prob、old_values，是旧策略的固定值，训练时用来算重要性采样比率
    # ==================== 2. Rollout Buffer ====================
class RolloutBuffer:
    """
    存储一条或多条 rollout 的 (s,a,r,done,V,log_prob)，
    并负责计算 GAE 优势与回报。
    本版本默认单环境（n_envs=1），但数组维度保留了 n_envs，便于扩展。
    """
    def __init__(
        self,
        buffer_size: int,                      # rollout 长度 T（每环境收集步数）
        observation_space: gym.Space,          # 观测空间，用于确定观测形状
        action_space: gym.Space,               # 动作空间，决定动作数组形状/dtype
        device: Union[torch.device, str] = "cpu", # 输出张量放置设备
        n_envs: int = 1,                       # 并行环境数，默认单环境
        gamma: float = 0.99,                   # 折扣因子
        gae_lambda: float = 0.95,              # GAE λ
    ):
        self.buffer_size = buffer_size
        self.obs_shape = observation_space.shape
        self.device = device
        self.n_envs = n_envs
        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.pos = 0                              # 当前写入位置

        # 根据动作空间类型决定动作数组形状
        if isinstance(action_space, gym.spaces.Discrete):
            self.action_shape = ()        # 离散动作是标量
            self.action_dtype = np.int64
        elif isinstance(action_space, gym.spaces.Box):
            self.action_shape = action_space.shape # 连续动作是向量
            self.action_dtype = np.float32
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

        self.reset()  # 一次性分配所有缓存数组

    def reset(self):
        # 所有数组维度为 (T, n_envs, ...)，为多环境并行预留（要点 1）
        self.observations = np.zeros((self.buffer_size, self.n_envs, *self.obs_shape), dtype=np.float32)
        self.actions = np.zeros((self.buffer_size, self.n_envs, *self.action_shape), dtype=self.action_dtype)
        self.rewards = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.dones = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.values = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)  # 旧策略 V(s)，训练时固定（要点 5）
        self.log_probs = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)  # 旧策略 logπ(a|s)，训练时固定（要点 5）
        self.advantages = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)  # GAE 优势，占位待计算
        self.returns = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)  # 回报 = 优势 + 值，用于 critic 目标
        self.pos = 0

    def add(self, obs, action, reward, done, value, log_prob):
        # 逐步写入一条转移；用 copy 避免外部数组被后续修改影响
        self.observations[self.pos] = np.asarray(obs, dtype=np.float32).copy()
        self.actions[self.pos] = np.asarray(action, dtype=self.action_dtype).copy()
        self.rewards[self.pos] = np.asarray(reward, dtype=np.float32).copy()
        self.dones[self.pos] = np.asarray(done, dtype=np.float32).copy()
        self.values[self.pos] = np.asarray(value, dtype=np.float32).copy()
        self.log_probs[self.pos] = np.asarray(log_prob, dtype=np.float32).copy()
        self.pos += 1

    def compute_returns_and_advantages(self, last_values: np.ndarray, dones: np.ndarray):
        """
        GAE 计算。last_values: V(s_T)；dones: 最后一步的 done 标志。
        实现要点 2：逆序递推，用 (1-done) 掩码截断跨 episode 的价值传播。
        """
        last_gae_lam = np.zeros(self.n_envs, dtype=np.float32)  # 每个环境的 GAE 累积项
        T = self.pos
        for step in reversed(range(T)):
            # 计算 next_value 与 next_non_terminal（1-done）
            if step == T - 1:
                # 最后一步：next 值来自外部传入的 V(s_T)，终止标志来自外部 dones
                next_non_terminal = 1.0 - dones
                next_values = last_values
            else:
                # 其余步：next 值是缓冲区中下一步的 V，done 是下一步的 done
                next_non_terminal = 1.0 - self.dones[step + 1]
                next_values = self.values[step + 1]
            # TD 误差 δ_t = r_t + γ V(s_{t+1}) (1-done) - V(s_t)
            delta = self.rewards[step] + self.gamma * next_values * next_non_terminal - self.values[step]
            # GAE 递推：A_t = δ_t + γλ (1-done) A_{t+1}，终止状态之后不传播
            last_gae_lam = delta + self.gamma * self.gae_lambda * next_non_terminal * last_gae_lam
            self.advantages[step] = last_gae_lam
        # 回报 = 优势 + 旧值，作为 critic 的回归目标（等价于 λ-return）
        self.returns[:T] = self.advantages[:T] + self.values[:T]

    def get(self, batch_size: int):
        """打乱后按 mini-batch 产出训练数据"""
        assert self.pos > 0, "Rollout buffer 为空"
        # 将 (T, n_envs, ...) 展平为 (T*n_envs, ...)（要点 3）
        obs = self._flatten(self.observations[: self.pos])
        actions = self._flatten(self.actions[: self.pos])
        old_values = self._flatten(self.values[: self.pos])
        old_log_prob = self._flatten(self.log_probs[: self.pos])
        advantages = self._flatten(self.advantages[: self.pos])
        returns = self._flatten(self.returns[: self.pos])

        # 打乱索引，避免数据分布与时间顺序相关（要点 4）
        indices = np.arange(obs.shape[0])
        np.random.shuffle(indices)

        # 按 batch_size 切分，迭代产出 mini-batch 并转为张量放到目标设备
        for start in range(0, len(indices), batch_size):
            end = start + batch_size
            idx = indices[start:end]
            yield (
                torch.as_tensor(obs[idx], device=self.device),             # 观测
                torch.as_tensor(actions[idx], device=self.device),         # 动作
                torch.as_tensor(old_values[idx], device=self.device),      # 旧策略 V(s)
                torch.as_tensor(old_log_prob[idx], device=self.device),    # 旧策略 logπ(a|s)
                torch.as_tensor(advantages[idx], device=self.device),      # GAE 优势
                torch.as_tensor(returns[idx], device=self.device),         # λ-return
            )

    def _flatten(self, arr: np.ndarray) -> np.ndarray:
        """把 (T, n_envs, ...) 摊平成 (T*n_envs, ...)，保留尾部特征维度"""
        return arr.reshape(-1, *arr.shape[2:])

    4. Actor-Critic 网络 ¶

    • 对应实现要点：正交初始化

      • 策略网络 Actor 最后一层 / 输出层 使用小增益 ( 约 0.01) 的正交初始化，让权重非常小，使得初始 \(logits \approx 0\)，经过 softmax 后策略 接近均匀分布，每个动作概率 约为 1/A

      • 好处：

        • 鼓励初期探索，不会一上来就锁定某个动作
        • 早期策略梯度信号小且平稳，避免因随机初始化导致策略立刻崩溃
        • 与 PPO 的 clip_ratio 配合，使首次更新时新旧策略差异不会过大

      • 目标网络 Critic 目标是拟合回报，不需要抑制初始输出，用标准 gain=1.0 即可保证梯度方差在层间稳定传递

      • 正交初始化本身的作用：让每层输入 - 输出保持近似等距，缓解深层网络的梯度消失 / 爆炸

    • 实现要点：

      1. MLP 共享特征提取层，actor、critic 共享底层表示，减少参数量
      2. 双分支分布支持：离散动作Categorical，连续动作Normal高斯分布；连续动作使用可学习 log_std
      3. evaluate_actions：训练阶段专用接口，输入轨迹里固定的 action，计算新策略下 log_prob、entropy、value，用来算比率 \(r_t\)，不再采样动作（非常关键的坑点）
      4. predict推理接口：支持 deterministic 确定性输出，评估时关闭随机性；连续动作自动 clip 到环境合法区间
    # ==================== 3. Actor-Critic 策略网络 ====================
class ActorCritic(nn.Module):
    # 使用离散动作空间，适用离散任务
    def __init__(self, obs_dim, act_dim, hidden_dim=64):
        super().__init__()
        # Actor 和 Critic 共享特征提取网络：参数量更小、样本效率更高，任务梯度可能会相互干扰
        self.shared_net = nn.Sequential(
            nn.Linear(obs_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Tanh(),
        )
        # Actor head: 正交初始化。输出每个动作logit，不做softmax
        # gain=0.01 使初始 logits 接近 0，softmax 后接近均匀分布，鼓励早期探索
        self.actor_head = nn.Linear(hidden_dim, act_dim)
        nn.init.orthogonal_(self.actor_head.weight, gain=0.01)
        nn.init.constant_(self.actor_head.bias, 0.)

        # Critic head: 正交初始化。输出状态价值V(s)
        # gain=1.0 保证价值头初始输出量级正常，梯度方差在层间稳定传递
        self.critic_head = nn.Linear(hidden_dim, 1)
        nn.init.orthogonal_(self.critic_head.weight, gain=1.0)
        nn.init.constant_(self.critic_head.bias, 0.)

        # 共享特征层也使用正交初始化，gain=sqrt(2) 适配 Tanh 激活
        for layer in self.shared_net:
            if isinstance(layer, nn.Linear):
                nn.init.orthogonal_(layer.weight, gain=np.sqrt(2))
                nn.init.constant_(layer.bias, 0.0)

    def get_action(self, obs):
        """收集rollout，采样动作"""
        # 共享特征提取
        feat = self.shared_net(obs)

        # 策略头输出 logits，构造离散动作分布
        logits = self.actor_head(feat)
        dist = Categorical(logits=logits)

        # 从当前策略采样动作，并记录 log_prob / entropy，供 PPO 损失使用
        action = dist.sample()
        log_prob = dist.log_prob(action)
        entropy = dist.entropy()
        # 价值头输出 V(s)，squeeze 去掉最后一维
        value = self.critic_head(feat).squeeze(-1)
        return action, log_prob, entropy, value

    def evaluate(self, obs, action):
        """ 训练阶段使用，给定状态+动作，不做采样，只评估
        用于计算r_t = new_logprob / old_logprob"""
        feat = self.shared_net(obs)
        # 用当前策略构造分布，但不再采样动作
        logits = self.actor_head(feat)
        dist = Categorical(logits=logits)

        # 对轨迹中固定的 action 计算新策略下的 log_prob，用于重要性采样比率
        log_prob = dist.log_prob(action)
        # 熵用于熵正则项
        entropy = dist.entropy()
        # 当前 critic 对这批状态的估值，用于价值损失
        value = self.critic_head(feat).squeeze(-1)
        return log_prob, entropy, value

# ==================== 3. Actor-Critic 策略网络 ====================
class ActorCriticPolicy(nn.Module):
    """
    共享 MLP 特征提取层，分别输出策略分布和价值估计。
    支持 Discrete（Categorical）和 Box（Normal）两类动作空间。
    """
    def __init__(
        self,
        observation_space: gym.Space,
        action_space: gym.Space,
        hidden_sizes: Tuple[int, ...] = (64, 64),
        activation: Type[nn.Module] = nn.Tanh,
    ):
        super().__init__()
        self.observation_space = observation_space
        self.action_space = action_space

        # ===== 新增：PPO 正交初始化辅助函数 =====
        def layer_init(layer, std: float = np.sqrt(2), bias_const: float = 0.0):
            """对 Linear 层做正交初始化，并把 bias 置为常数。"""
            nn.init.orthogonal_(layer.weight, std)
            nn.init.constant_(layer.bias, bias_const)
            return layer
        # ===== 新增结束 =====

        # 将观测空间展平为一维向量维度
        obs_dim = int(np.prod(observation_space.shape))
        layers = []
        in_dim = obs_dim
        for h in hidden_sizes:
            # layers.extend([nn.Linear(in_dim, h), activation()])
            # ===== 修改：隐藏层 Linear 用正交初始化 (gain=√2) =====
            # 正交初始化保持层间信号等距，缓解深层网络梯度消失/爆炸
            layers.extend([layer_init(nn.Linear(in_dim, h), std=np.sqrt(2)), activation()])

            in_dim = h
        # 共享特征提取器：actor / critic 共用底层表示
        self.mlp_extractor = nn.Sequential(*layers)
        self.latent_dim = in_dim

        # 价值头
        # self.value_net = nn.Linear(self.latent_dim, 1)
        # ===== 修改：价值头正交初始化，gain=1.0 =====
        # 价值函数对初始化的量级比较敏感，gain=1 是 PPO 中的常用选择
        self.value_net = layer_init(nn.Linear(self.latent_dim, 1), std=1.0)

        # 策略头
        if isinstance(action_space, gym.spaces.Discrete):
            # 离散动作：输出每个动作的 logit 维度
            self.action_dim = action_space.n
            # self.action_net = nn.Linear(self.latent_dim, self.action_dim)
            # ===== 修改：策略头正交初始化，gain=0.01 =====
            # 使用很小的 gain，使得初始策略接近均匀分布，避免早期过拟合到某个动作
            self.action_net = layer_init(nn.Linear(self.latent_dim, self.action_dim), std=0.01)

            self.dist_type = "categorical"
        elif isinstance(action_space, gym.spaces.Box):
            # 连续动作：输出每个动作维度的均值
            self.action_dim = action_space.shape[0]

            # self.action_net = nn.Linear(self.latent_dim, self.action_dim)
            # 可学习的对数标准差
            # self.log_std = nn.Parameter(torch.zeros(1, self.action_dim))
            # ===== 修改：策略头正交初始化，gain=0.01 =====
            self.action_net = layer_init(nn.Linear(self.latent_dim, self.action_dim), std=0.01)
            # 可学习的对数标准差
            # ===== 新增说明：log_std 保持全零即可 =====
            # nn.Parameter(torch.zeros(...)) 本身就是“初始化到零”，
            # 符合 PPO 中“初始动作分布均值约等于 0、std=1”的惯例，不需要再正交初始化。
            self.log_std = nn.Parameter(torch.zeros(1, self.action_dim))

            self.dist_type = "normal"

            # 记录动作上下界，用于推理时 clip 到合法区间
            low = np.asarray(action_space.low, dtype=np.float32)
            high = np.asarray(action_space.high, dtype=np.float32)
            # 只有上下界均有限时才启用 clip
            self.bounded = np.all(np.isfinite(low)) and np.all(np.isfinite(high))
            self.low = low
            self.high = high
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

    def forward(self, obs: torch.Tensor):
        # 共享特征提取
        features = self.mlp_extractor(obs)
        # 价值头输出 V(s)
        values = self.value_net(features).squeeze(-1)
        if self.dist_type == "categorical":
            # 离散动作：logits -> Categorical 分布
            logits = self.action_net(features)
            dist = Categorical(logits=logits)
        else:
            # 连续动作：均值 + 可学习 std -> Normal 分布
            mean = self.action_net(features)
            dist = Normal(mean, self.log_std.exp().expand_as(mean))
        return dist, values

    def get_distribution(self, obs: torch.Tensor):
        # 只取策略分布，忽略价值
        return self.forward(obs)[0]

    def predict_values(self, obs: torch.Tensor):
        # 只取价值估计，忽略策略分布
        return self.forward(obs)[1]

    def evaluate_actions(self, obs: torch.Tensor, actions: torch.Tensor):
        """训练时评估：返回 V(s), log_pi(a|s), H(pi(s))"""
        # 前向得到当前策略分布和当前价值
        dist, values = self.forward(obs)
        if self.dist_type == "categorical":
            # 离散动作：标量动作，log_prob/entropy 不需要按维度求和
            log_prob = dist.log_prob(actions)
            entropy = dist.entropy()
        else:
            # 连续动作：多维度动作，log_prob/entropy 按最后一维求和得到联合量
            log_prob = dist.log_prob(actions).sum(dim=-1)
            entropy = dist.entropy().sum(dim=-1)
        return values, log_prob, entropy

    def predict(self, obs: torch.Tensor, deterministic: bool = False):
        """推理：返回 numpy 动作"""
        # 推理阶段不需要梯度
        with torch.no_grad():
            dist = self.get_distribution(obs)
            if self.dist_type == "categorical":
                if deterministic:
                    # 确定性评估：取概率最大的动作
                    action = torch.argmax(dist.probs, dim=-1)
                else:
                    # 随机采样
                    action = dist.sample()
                return action.cpu().numpy()
            else:
                if deterministic:
                    # 确定性评估：取分布均值
                    action = dist.mean
                else:
                    # 随机采样
                    action = dist.sample()
                action = action.cpu().numpy()
                # 若动作空间有界，则裁剪到合法区间
                if self.bounded:
                    action = np.clip(action, self.low, self.high)
                    return action
                # 注意：非 bounded 的连续动作空间需要在此返回 action

    5. 算法基类与 On-Policy 基类 ¶

    • 实现要点：

      • BaseAlgorithm：通用 RL 算法抽象，封装随机种子、predict 对外推理接口

        • 统一设备选择、动作空间校验、单环境 n_envs=1 约定；predict 只做推理，不更新 RunningMeanStd 统计量。

      • OnPolicyAlgorithm：on-policy 专属父类，绑定 rollout buffer；on-policy 算法每一轮更新前必须重新采集轨迹，旧轨迹不能复用多轮 rollout

        • collect_rollouts 开头 rollout_buffer.reset()，保证每轮 PPO 更新使用新轨迹。
        • rollout_buffer_class 与 rollout_buffer 占位必须在 super().__init__ 前设置，因为 BaseAlgorithm.__init__ 会调用 _setup_model()，动态分派到 OnPolicyAlgorithm._setup_model。

      • collect_rollouts：策略 eval 模式下采集轨迹；支持 RunningMeanStd 在线更新观测均值方差；

        • 注意：存入 buffer 是原始未裁剪动作，环境 step 使用裁剪后的动作（连续空间保护环境）
        • buffer 中保存的是归一化后的观测；环境交互仍使用原始观测；action_raw_np 入 buffer，action_step_np 经 clip 后送入 env.step。

      • 采集结束后，预测最后一个状态的last_values，作为 GAE 的 bootstrap 目标

        • 最后观测需与采集时一致做归一化；last_dones 用于 GAE 在终止状态屏蔽 bootstrap。
        • 若区分 terminated / truncated，GAE 的 done 最好使用 terminated；truncated 时仍可用 last_values bootstrap，避免 time-limit 截断被误当真正终止。

        self,

        policy: Type[nn.Module],
        learning_rate: Union[float, Callable] = 3e-4,  # 学习率，可为常数或调度函数（要点 8：支持线性退火）
        n_steps: int = 2048,                            # 每轮 rollout 采集步数

        gae_lambda: float = 0.95,

        max_grad_norm: float = 0.5,                     # 梯度全局裁剪范数（要点 7）
        normalize_observations: bool = False,           # 是否开启观测 RunningMeanStd 归一化（要点 3）
        verbose: int = 0,                               # 日志等级

        self.policy_class = policy

        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.ent_coef = ent_coef
        self.vf_coef = vf_coef
        self.max_grad_norm = max_grad_norm

            self.action_shape = ()    # 离散动作为标量

            self.action_shape = self.action_space.shape
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

        self.num_timesteps = 0          # 累计环境交互步数
        self._n_updates = 0             # 累计梯度更新次数（用于调度器）
        self.ep_info_buffer = deque(maxlen=100)  # 最近 100 个回合回报，用于日志

        self.optimizer = None           # 优化器，由子类创建
        self.obs_rms = None             # 观测归一化统计量，可选

        if seed is not None:
            self.set_random_seed(seed)

        torch.manual_seed(seed)
        if torch.cuda.is_available():
            torch.cuda.manual_seed_all(seed)

    def _setup_model(self):
        # 抽象方法，由具体算法子类实现
        raise NotImplementedError

    def predict(self, observation: np.ndarray, deterministic: bool = False):
        """对外接口：输入单步观测，输出动作"""
        obs = np.asarray(observation, dtype=np.float32)
        # 补 batch 维度（单步观测 -> (1, *obs_shape)）
        if obs.ndim == len(self.observation_space.shape):
            obs = obs.reshape(1, *self.observation_space.shape)

        # 若开启观测归一化，推理时使用训练阶段维护的 obs_rms 做归一化，但不更新统计量
        if self.obs_rms is not None:

        with torch.no_grad():
            action = self.policy.predict(torch.as_tensor(obs, device=self.device), deterministic=deterministic)
        return action[0]  # 去掉 batch 维度


class OnPolicyAlgorithm(BaseAlgorithm):
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module] = ActorCriticPolicy,
        rollout_buffer_class: Type[RolloutBuffer] = RolloutBuffer, # 可替换 buffer 实现
        **kwargs,
    ):
        super().__init__(env=env, policy=policy,** kwargs)
        self.rollout_buffer_class = rollout_buffer_class
        self.rollout_buffer = None

    def _setup_model(self):
        # 创建策略网络（Actor-Critic 共享特征）
        self.policy = self.policy_class(self.observation_space, self.action_space).to(self.device)

        # 可选观测归一化：统计量形状为展平后的观测维度
        if self.normalize_observations:
            self.obs_rms = RunningMeanStd((int(np.prod(self.observation_space.shape)),))

        # 创建 rollout buffer；on-policy 算法每轮更新前要重新填满它（要点 2）
        self.rollout_buffer = self.rollout_buffer_class(
            self.n_steps,
            self.observation_space,
            self.action_space,
            device=self.device,
            n_envs=self.n_envs,
            gamma=self.gamma,
            gae_lambda=self.gae_lambda,
        )

    def collect_rollouts(self, env: gym.Env, total_timesteps: int):
        """
        采集 n_steps 条经验。若 total_timesteps 先到，则提前结束（支持最后一段不完整 rollout）。
        返回 (last_values, last_dones) 用于 GAE bootstrap。
        """
        # 每轮采集前清空 buffer；on-policy 旧轨迹不可复用（要点 2）
        self.rollout_buffer.reset()
        # 采集阶段使用 eval 模式，关闭 dropout/BN 等训练期行为（要点 3）
        self.policy.eval()

        n_steps = 0
        last_dones = np.zeros(self.n_envs, dtype=np.float32)

        # 采集 n_steps 步，或总步数达到上限时提前结束
        while n_steps < self.n_steps and self.num_timesteps < total_timesteps:
            raw_obs = self._last_obs  # shape: (1, obs_dim)，原始未归一化观测

            # ---- 观测归一化 ----
            if self.obs_rms is not None:
                # 在线更新统计量；仅训练期更新（要点 3）
                flat = raw_obs.reshape(self.n_envs, -1)
                self.obs_rms.update(flat)
                obs_input = self.obs_rms.normalize(flat).reshape(raw_obs.shape).astype(np.float32)
            else:
                obs_input = raw_obs  # 归一化后的观测（或原始观测）

            obs_t = torch.as_tensor(obs_input, dtype=torch.float32, device=self.device)

            # ---- 采样动作 ----
            with torch.no_grad():
                dist = self.policy.get_distribution(obs_t)   # 当前策略分布
                action_t = dist.sample()                     # 采样动作（未裁剪）
                if self.policy.dist_type == "categorical":
                    log_prob_t = dist.log_prob(action_t)     # 离散动作 log_prob 为标量
                else:
                    log_prob_t = dist.log_prob(action_t).sum(dim=-1)  # 连续动作按维度求和
                value_t = self.policy.predict_values(obs_t)  # 旧策略 V(s)，存入 buffer

            # 保存未裁剪动作到 buffer；环境 step 使用裁剪后的动作（要点 3）
            action_raw_np = action_t.cpu().numpy()
            if self.policy.dist_type == "normal" and self.policy.bounded:
                # 连续有界动作：clip 到合法区间保护环境，但 buffer 里仍存原始动作
                action_step_np = np.clip(action_raw_np, self.policy.low, self.policy.high)
            else:
                action_step_np = action_raw_np

            step_action = action_step_np[0]  # 去掉 env 维度后传给 env.step
            new_obs, reward, terminated, truncated, info = env.step(step_action)
            done = float(terminated or truncated)  # 终止或截断均视为 episode 结束

            self.num_timesteps += 1
            # 写入 buffer：注意 action 存原始未裁剪动作，与 log_prob 对应
            self.rollout_buffer.add(
                obs_input,
                action_raw_np.reshape(self.n_envs, *self.action_shape),
                np.array([reward], dtype=np.float32),
                np.array([done], dtype=np.float32),
                value_t.cpu().numpy().reshape(self.n_envs),
                log_prob_t.cpu().numpy().reshape(self.n_envs),
            )

            # 记录回合回报（需要 env 被 Monitor 包装，或在 info 中提供 episode）
            if done > 0.5 and isinstance(info, dict) and "episode" in info:
                self.ep_info_buffer.append(info["episode"]["r"])

            # 单环境 done 后手动 reset（多环境时可用 VectorEnv 自动 reset）
            if done > 0.5:
                new_obs, _ = env.reset()

            # 更新最近观测，保持 (n_envs, *obs_shape) 形状
            self._last_obs = np.asarray(new_obs, dtype=np.float32).reshape(self.n_envs, *self.observation_space.shape)
            n_steps += 1
            last_dones = np.array([done], dtype=np.float32)

        # ---- 计算最后状态的 V，用于 GAE bootstrap（要点 4）----
        last_obs = self._last_obs
        if self.obs_rms is not None:
            # 注意：这里只 normalize，不 update，避免用最后一步观测污染统计量
            last_obs = self.obs_rms.normalize(last_obs.reshape(self.n_envs, -1)).reshape(last_obs.shape).astype(np.float32)

        with torch.no_grad():
            last_values = self.policy.predict_values(torch.as_tensor(last_obs, dtype=torch.float32, device=self.device))

        # 返回 bootstrap 值与最后一步 done 标志，供 compute_returns_and_advantages 使用
        return last_values.cpu().numpy().reshape(self.n_envs), last_dones

    6. PPO 主类 ¶

    • 实现要点（全部 PPO 核心工程 trick）
      1. 支持动态调度：learning_rate、clip_range可以传入函数，实现线性退火
      2. 优势归一化：normalize_advantage=True时，整批 rollout 统一做 z-score 归一（SB3 原版方案）
      3. PPO clip 策略损失：\(r_t=\exp(\log\pi_{new}-\log\pi_{old})，min(r\cdot A, \text{clip}(r)\cdot A)\)
      4. 可选价值裁剪clip_range_vf：SB3 经典实现，约束 critic 更新幅度，取两个 MSE 的最大值
      5. 熵损失：entropy_loss = -mean(entropy)，加到总 loss；最小化 loss 等价最大化熵，鼓励探索
      6. 全局梯度裁剪：clip_grad_norm_，上限max_grad_norm
      7. KL 早停：使用 \(\text{approx_kl}=E\left[ e^{\log r}-1-\log r \right]\) ；epoch 内 KL 超过target_kl直接 break，停止本轮所有 epoch 更新
      8. TensorBoard 日志：记录 policy_loss、value_loss、熵、KL、lr、clip 范围
      9. learn主循环：标准流程：收集 rollout → 计算 GAE → train 更新，循环直到总 timestep 达标
      10. save/load：持久化包含 obs_rms 的均值方差，支持断点续训
    # ==================== 5. PPO 主类 ====================
class PPO(OnPolicyAlgorithm):
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module] = ActorCriticPolicy,
        learning_rate: Union[float, Callable] = 3e-4,       # 学习率，可为常数或进度函数（要点 1）
        n_steps: int = 2048,                                # 每轮 rollout 长度
        batch_size: int = 64,                               # minibatch 大小
        n_epochs: int = 10,                                 # 同一批数据的训练轮数（要点 5：多 epoch 复用）
        gamma: float = 0.99,
        gae_lambda: float = 0.95,
        clip_range: Union[float, Callable] = 0.2,           # PPO clip ε，可为常数或进度函数（要点 1）
        clip_range_vf: Optional[Union[float, Callable]] = None,  # 价值裁剪范围，None 表示不做价值裁剪（要点 4）
        normalize_advantage: bool = True,                   # 是否整批做优势归一化（要点 2）
        ent_coef: float = 0.0,                              # 熵正则系数（要点 5）
        vf_coef: float = 0.5,                               # 价值损失权重
        max_grad_norm: float = 0.5,                         # 梯度全局裁剪上限（要点 6）
        target_kl: Optional[float] = None,                  # KL 早停阈值（要点 7）
        normalize_observations: bool = False,
        tensorboard_log: Optional[str] = None,
        verbose: int = 0,
        seed: Optional[int] = None,
        device: Union[torch.device, str] = "auto",
    ):
        # 调用父类完成策略、buffer、obs_rms 的初始化（父类 _setup_model 不含优化器）
        super().__init__(
            env=env,
            policy=policy,
            learning_rate=learning_rate,
            n_steps=n_steps,
            gamma=gamma,
            gae_lambda=gae_lambda,
            ent_coef=ent_coef,
            vf_coef=vf_coef,
            max_grad_norm=max_grad_norm,
            normalize_observations=normalize_observations,
            verbose=verbose,
            seed=seed,
            device=device,
        )

        # PPO 特有超参数
        self.batch_size = batch_size
        self.n_epochs = n_epochs
        self.clip_range = clip_range
        self.clip_range_vf = clip_range_vf
        self.normalize_advantage = normalize_advantage
        self.target_kl = target_kl
        self.tensorboard_log = tensorboard_log
        # 仅当配置了日志目录时创建 SummaryWriter
        self.writer = SummaryWriter(tensorboard_log) if tensorboard_log else None

        self._total_timesteps = 0  # 在 learn 时设置，用于 schedule 的进度计算

    # -------------------- 模型与工具函数 --------------------
    def _setup_model(self):
        """先调用父类创建 policy / buffer / obs_rms，再创建 Adam 优化器"""
        super()._setup_model()
        # 优化器在构造时用进度 0 的学习率初始化；之后每轮 train 会重新设置 lr
        self.optimizer = optim.Adam(self.policy.parameters(), lr=self._get_lr(0.0))

    def _get_lr(self, progress: float) -> float:
        # 学习率调度：可调用则按 progress 计算，否则视为常数（要点 1）
        if callable(self.learning_rate):
            return self.learning_rate(progress)
        return float(self.learning_rate)

    def _get_clip_range(self, progress: float) -> float:
        # clip 范围调度：同理支持线性退火（要点 1）
        if callable(self.clip_range):
            return self.clip_range(progress)
        return float(self.clip_range)

    def _get_clip_range_vf(self, progress: float) -> Optional[float]:
        # 价值裁剪范围的调度；None 表示禁用价值裁剪（要点 4）
        if self.clip_range_vf is None:
            return None
        if callable(self.clip_range_vf):
            return self.clip_range_vf(progress)
        return float(self.clip_range_vf)

    def _get_constructor_parameters(self) -> Dict[str, Any]:
        """保存/加载时记录构造参数（要点 10）"""
        return dict(
            env=None,       # env 在 load 时单独注入，避免 pickle 环境
            policy=self.policy_class,
            learning_rate=self.learning_rate,
            n_steps=self.n_steps,
            batch_size=self.batch_size,
            n_epochs=self.n_epochs,
            gamma=self.gamma,
            gae_lambda=self.gae_lambda,
            clip_range=self.clip_range,
            clip_range_vf=self.clip_range_vf,
            normalize_advantage=self.normalize_advantage,
            ent_coef=self.ent_coef,
            vf_coef=self.vf_coef,
            max_grad_norm=self.max_grad_norm,
            target_kl=self.target_kl,
            normalize_observations=self.normalize_observations,
            tensorboard_log=self.tensorboard_log,
            verbose=self.verbose,
            seed=self.seed,
            device=str(self.device),
        )

    # -------------------- 训练核心 --------------------
    def train(self):
        """
        使用 RolloutBuffer 中的数据进行 PPO 多 epoch 更新。
        包含：advantage 归一化、策略 clip、value clip（可选）、entropy、KL early stopping。
        """
        # 训练模式（与采集阶段的 eval 模式切换）
        self.policy.train()

        # 当前训练进度，用于学习率 / clip range 的 schedule（要点 1）
        progress = self.num_timesteps / self._total_timesteps if self._total_timesteps > 0 else 0.0
        clip_range = self._get_clip_range(progress)
        clip_range_vf = self._get_clip_range_vf(progress)
        lr = self._get_lr(progress)

        # 手动更新学习率（不依赖 LambdaLR，避免 total_timesteps 未知的问题）
        for param_group in self.optimizer.param_groups:
            param_group["lr"] = lr

        # ---- 优势归一化（可选，整个 batch 做一次，要点 2） ----
        # 注意：这里是“整批 rollout 归一化”，而不是 minibatch 归一化
        if self.normalize_advantage:
            adv_flat = self.rollout_buffer.advantages[: self.rollout_buffer.pos].reshape(-1)
            adv_flat = (adv_flat - adv_flat.mean()) / (adv_flat.std() + 1e-8)  # z-score，加 eps 防除零
            self.rollout_buffer.advantages[: self.rollout_buffer.pos] = adv_flat.reshape(
                self.rollout_buffer.pos, self.n_envs
            )

        # 记录损失，用于日志（要点 8）
        entropy_losses, policy_losses, value_losses, approx_kl_divs = [], [], [], []
        continue_training = True

        # -------------------- 多 epoch 更新（要点 5） --------------------
        for epoch in range(self.n_epochs):
            approx_kl_divs_epoch = []

            # buffer.get 会打乱并产出 minibatch；每个 epoch 重新打乱一次
            for rollout_data in self.rollout_buffer.get(self.batch_size):
                obs, actions, old_values, old_log_prob, advantages, returns = rollout_data

                # 重新评估当前策略下的 log_prob、熵、价值（要点 3：不采样，只评估固定 action）
                values, log_prob, entropy = self.policy.evaluate_actions(obs, actions)
                # 统一转为 float32，避免某些算子产生 dtype 不一致
                values = values.float()
                log_prob = log_prob.float()
                advantages = advantages.float()

                # ---- 策略损失（PPO-Clip，要点 3） ----
                # 重要性采样比率 r_t = exp(logπ_new - logπ_old)
                ratio = torch.exp(log_prob - old_log_prob)
                # 未裁剪项：r_t * A_t
                policy_loss_1 = advantages * ratio
                # 裁剪项：clip(r_t, 1-ε, 1+ε) * A_t
                policy_loss_2 = advantages * torch.clamp(ratio, 1 - clip_range, 1 + clip_range)
                # 取 min 后加负号变成损失（最大化目标等价于最小化负目标）
                policy_loss = -torch.min(policy_loss_1, policy_loss_2).mean()

                # ---- 价值损失（可选 value clipping，要点 4） ----
                if clip_range_vf is None:
                    # 无价值裁剪：普通 MSE
                    value_loss = F.mse_loss(values, returns)
                else:
                    # SB3 风格：限制新 value 相对旧 value 的变化幅度，取 clip/不 clip 中较大者
                    values_clipped = old_values + torch.clamp(
                        values - old_values, -clip_range_vf, clip_range_vf
                    )
                    value_loss1 = F.mse_loss(returns, values)
                    value_loss2 = F.mse_loss(returns, values_clipped)
                    # 取两者最大值：即使裁剪后损失更小，也用未裁剪的较大损失来更新，防止 critic 跳变
                    value_loss = torch.max(value_loss1, value_loss2)

                # ---- 熵奖励（鼓励探索，要点 5） ----
                # 熵损失取负号：最小化 loss 等价于最大化熵
                entropy_loss = -entropy.mean()

                # ---- 总损失与反向传播 ----
                # 总损失 = 策略损失 + c_v * 价值损失 + c_s * 熵损失
                loss = policy_loss + self.vf_coef * value_loss + self.ent_coef * entropy_loss

                self.optimizer.zero_grad()
                loss.backward()
                # 全局梯度裁剪，约束参数梯度二范数（要点 6）
                nn.utils.clip_grad_norm_(self.policy.parameters(), self.max_grad_norm)
                self.optimizer.step()

                # ---- 近似 KL，用于 early stopping（要点 7） ----
                # 公式：E[exp(log_ratio) - 1 - log_ratio]，无偏且比直接 mean(log_ratio) 数值更稳
                with torch.no_grad():
                    log_ratio = log_prob - old_log_prob
                    approx_kl = torch.mean((torch.exp(log_ratio) - 1) - log_ratio).item()
                    approx_kl_divs_epoch.append(approx_kl)

                # 累积损失用于日志
                policy_losses.append(policy_loss.item())
                value_losses.append(value_loss.item())
                entropy_losses.append(entropy_loss.item())

            mean_epoch_kl = np.mean(approx_kl_divs_epoch)
            approx_kl_divs.append(mean_epoch_kl)

            # KL 超过阈值则提前结束所有 epoch（要点 7）
            # 使用 mean_epoch_kl > target_kl 判断；常见变体是 > 1.5 * target_kl
            if self.target_kl is not None and mean_epoch_kl > self.target_kl:
                if self.verbose > 0:
                    print(
                        f"  [early stop] epoch {epoch + 1}/{self.n_epochs}, "
                        f"KL={mean_epoch_kl:.5f} > target_kl={self.target_kl:.5f}"
                    )
                continue_training = False
                break

        self._n_updates += 1

        # -------------------- TensorBoard 日志（要点 8） --------------------
        if self.writer is not None:
            self.writer.add_scalar("train/policy_loss", np.mean(policy_losses), self._n_updates)
            self.writer.add_scalar("train/value_loss", np.mean(value_losses), self._n_updates)
            self.writer.add_scalar("train/entropy_loss", np.mean(entropy_losses), self._n_updates)
            self.writer.add_scalar("train/approx_kl", np.mean(approx_kl_divs), self._n_updates)
            self.writer.add_scalar("train/clip_range", clip_range, self._n_updates)
            self.writer.add_scalar("train/lr", lr, self._n_updates)

    # -------------------- 主学习循环 --------------------
    def learn(self, total_timesteps: int, log_interval: int = 1):
        """
        主入口：反复收集 rollout -> 计算 GAE -> train()，直到达到 total_timesteps（要点 9）。
        """
        self._total_timesteps = total_timesteps  # 供 schedule 计算 progress
        self._start_time = time.time()           # 用于计算 fps

        # 初始化环境
        obs, _ = self.env.reset()
        # 初始观测以 (n_envs, *obs_shape) 形状保存
        self._last_obs = np.asarray(obs, dtype=np.float32).reshape(
            self.n_envs, *self.observation_space.shape
        )

        while self.num_timesteps < total_timesteps:
            # ---- 1. 收集 rollout（on-policy：每轮重新采集，不复用旧轨迹） ----
            last_values, last_dones = self.collect_rollouts(self.env, total_timesteps)

            # 极端情况下 rollout 为空（如 total_timesteps 已达标）直接退出
            if self.rollout_buffer.pos == 0:
                break

            # ---- 2. 计算 GAE 优势和回报 ----
            self.rollout_buffer.compute_returns_and_advantages(last_values, last_dones)

            # ---- 3. 更新策略（多 epoch + KL 早停） ----
            self.train()

            # ---- 4. 打印日志 ----
            if self.verbose > 0 and self._n_updates % log_interval == 0:
                elapsed = time.time() - self._start_time
                fps = int(self.num_timesteps / elapsed) if elapsed > 0 else 0
                # 最近 100 回合平均回报，作为训练效果的核心指标
                mean_reward = (
                    np.mean(list(self.ep_info_buffer)) if len(self.ep_info_buffer) > 0 else -np.inf
                )
                print(
                    f"updates={self._n_updates:4d} | "
                    f"steps={self.num_timesteps:7d} | "
                    f"fps={fps:4d} | "
                    f"mean_reward(last100)={mean_reward:.2f}"
                )
                if self.writer is not None:
                    self.writer.add_scalar("rollout/ep_rew_mean", mean_reward, self.num_timesteps)
        # 训练结束关闭 TensorBoard writer
        if self.writer is not None:
            self.writer.close()

        return self

    # -------------------- 保存 / 加载（要点 10） --------------------
    def save(self, path: str):
        """保存模型参数、优化器、观测归一化统计量和训练进度"""
        # 确保目录存在（path 只有文件名时用当前目录）
        os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
        data = {
            "policy_state_dict": self.policy.state_dict(),         # 策略网络权重
            "optimizer_state_dict": self.optimizer.state_dict(),   # 优化器状态（Adam 动量等）
            "hyperparams": self._get_constructor_parameters(),     # 重建模型所需的构造参数
            "num_timesteps": self.num_timesteps,                   # 已交互步数，断点续训用
            "_n_updates": self._n_updates,                         # 已更新次数
        }
        # 观测归一化统计量，必须一并保存才能正确恢复推理
        if self.obs_rms is not None:
            data["obs_rms"] = {
                "mean": self.obs_rms.mean,
                "var": self.obs_rms.var,
                "count": self.obs_rms.count,
            }
        else:
            data["obs_rms"] = None

        torch.save(data, path)
        if self.verbose > 0:
            print(f"[save] {path}")

    @classmethod
    def load(cls, path: str, env: gym.Env, device: Union[torch.device, str] = "auto"):
        """
        从 save 文件恢复模型。需要传入新的 env（也可以把 env 存入 hyperparams 恢复）。
        """
        # 先加载到 CPU，再根据目标 device 迁移
        data = torch.load(path, map_location="cpu")
        hyperparams = data["hyperparams"]
        hyperparams["env"] = env              # 注入新的 env
        hyperparams["device"] = device

        # 用保存的超参重建模型
        model = cls(**hyperparams)
        # 恢复网络权重与优化器状态
        model.policy.load_state_dict(data["policy_state_dict"])
        model.optimizer.load_state_dict(data["optimizer_state_dict"])

        # 恢复观测归一化统计量
        if data["obs_rms"] is not None:
            model.obs_rms.mean = data["obs_rms"]["mean"]
            model.obs_rms.var = data["obs_rms"]["var"]
            model.obs_rms.count = data["obs_rms"]["count"]

        # 恢复训练进度（断点续训）
        model.num_timesteps = data.get("num_timesteps", 0)
        model._n_updates = data.get("_n_updates", 0)
        return model

    8. 逐模块坑点笔记 ¶

    1. 旧策略参数一定不能在更新中被修改

      old_logp / old_value 全部在 rollout 收集阶段torch.no_grad()下算出；更新时只拿它们做比值，不要重新计算旧 logp。若误用新策略重算 old_logp，ratio 恒等于 1，PPO clip 完全失效。

    2. 优势归一化：整批归一 vs minibatch 内归一，二选一但不要混用

      本实现采用 SB3 风格的整批 rollout 归一：一批轨迹在训练前统一做一次 z-score，之后所有 epoch/minibatch 共用同一份归一化优势。

      另一种主流方案是 minibatch 内归一：每个 minibatch 单独归一，相当于给每个小批的优势重新做尺度。

      两者都是有效工程选择，但不能一半整批一半 minibatch；且归一化必须发生在计算 policy/value loss 之前，不能在 loss 内对 advantages 再做一次归一化（会让不同 minibatch 的优势尺度不一致）。

    3. GAE 反向遍历，done 位置截断价值

      终止状态 \(s_T\) 之后没有价值，next_value=0（用 1-done 掩码把 \(V(s_{t+1})\) 项清零）；不处理 done 会把跨 episode 的价值混在一起，优势完全错误。

      注意 terminated 和 truncated 语义不同：terminated=True 是真正终止（后续无价值），truncated=True 是时间截断（理论上后续仍有价值，可按需做 bootstrap）。

    4. KL 是监控信号，不是损失项

      很多新手误把 KL 加到 loss 里，那就变成带 KL 惩罚的 PPO（PPO-Penalty），不是原生 Clip-PPO；RLHF 里的 KL 惩罚是另外一套（对参考策略的惩罚，不属于 PPO 主体）。本实现用 KL 仅做早停判断。

    5. 梯度裁剪是对网络全部参数的全局范数，不是单独裁剪每层梯度

      用nn.utils.clip_grad_norm_（全局二范数），不是 clip_grad_value_（逐元素裁剪）。两者语义完全不同，后者会破坏不同层之间的相对梯度尺度。

    6. 熵系数不要太大

      CartPole 这类简单任务0.01足够；太大熵鼓励随机探索，永远不收敛。连续任务有时熵系数要更小甚至 0。

    7. 学习率退火：线性衰减到 0

      固定学习率后期容易震荡，这是 OpenAI 原版 PPO 标配。本实现通过可调用 learning_rate(progress) 实现，progress = num_timesteps / total_timesteps ∈ [0,1]。

    8. 分布数值稳定性

      exp(logp_new - logp_old) 求 ratio，不要直接存概率做除法，防止数值下溢。同时 ratio 和 log_prob 全程用 float32，不要混用 float64/float16。

    9. 连续多维度动作的 log_prob / entropy 必须按维度求和

      若 action_dim > 1，dist.log_prob(actions) 形状是 (batch, action_dim)，必须 .sum(dim=-1) 得到联合 log_prob；否则 ratio 形状对不上，或按元素做比导致 batch 维度广播错误。离散动作只需标量 log_prob，不要 sum。

    10. 动作 clip 与 log_prob 的对应关系

      连续有界环境（如 SUMO、Box 动作）常做 " 存原始动作、step 用 clip 后动作 " 的处理：buffer 里存的是网络采样出的原始动作，对应 log_prob 也是原始动作的；env.step 只接受合法范围内的动作。这会让 " 实际执行动作 " 与 " 计算 log_prob 的动作 " 略有偏差，属于工程折中（SB3 同款）。若要严格一致，应改用 tanh-squash 的分布变换（见第 9 节）。

    11. 观测归一化：训练更新，评估固定

      RunningMeanStd.update 只在训练 rollout 中调用；评估、推理、以及计算 last_values 的 bootstrap 观测时，只能 normalize 不能 update，否则统计量被污染，推理分布与训练不一致。

    12. 评估必须 deterministic=True

      评估时用 predict(obs, deterministic=True)（离散取 argmax、连续取均值），关闭采样噪声；若误用随机采样，评估曲线会抖动，甚至显示比训练时差很多。

    13. _total_timesteps 在 train 之前必须已设置

      若单独调用 train() 而没有经过 learn()，_total_timesteps=0 会导致 progress=0，调度器退化为起点值，不易察觉。建议始终通过 learn() 进入训练，或在 train() 里加断言。

    14. buffer 里的 pos 与 compute_returns_and_advantages 的 T 必须一致

      最后一个不完整 rollout（num_timesteps 提前达标）会导致 pos < buffer_size，GAE 与 get() 只能用 [:pos]。若误用 buffer_size 会读到全零的 padding，产生错误优势。

    15. on-policy 约束：每次 train 前必须重新 collect rollout

      旧轨迹不能跨 rollout 重复使用。本实现每轮 collect_rollouts 先 buffer.reset()，但 self._last_obs 保留（环境状态连续），这是正确的；不要把上一轮的 buffer 数据拿来继续训练。

    补充说明 & 踩坑清单 ¶

    1. KL 计算公式：这里使用 \(KL \approx E\left[ e^{\log r}-1-\log r \right]\)，是 PPO 论文常用的一阶近似，不是精确 KL。精确 KL 要用整个分布算 KL(old || new)，代价高且不需要
    2. 连续动作：log_std 为全局可学习参数；也可以改成网络输出 log_std，根据任务选择。前者更稳定、参数少；后者表达力更强但更易过拟合。
    3. 观测归一化：连续控制（MuJoCo、SUMO 交通）强烈建议开启；CartPole 这类离散简单环境可关闭。
    4. value clip 默认关闭，属于可选 trick，部分任务会不稳定，需要消融实验验证。开启时不要与 normalize_advantage 的效果混淆——前者限制 critic 更新幅度，后者只缩放优势。
    5. 熵系数ent_coef：离散任务一般 0.01；连续控制经常设置为 0，防止探索爆炸
    6. KL 早停阈值：本实现用 mean_epoch_kl > target_kl；SB3 常见变体是 > 1.5 * target_kl，防止单 minibatch 噪声误触发，二者都可。
    7. terminated vs truncated：本实现把二者合并成 done 处理（都截断价值），简单环境够用；若追求严格正确，truncated 应做 bootstrap（next_value = V(s_T) 而非 0），MuJoCo 这类时间限制环境尤其明显。

    10. 思考题 ¶

    1. 为什么 PPO 可以对同一批轨迹多次 epoch 更新，而原生 TRPO 不适合？

      • PPO 的约束是 " 软 " 的：clip 把 ratio 限制在 \([1-\epsilon, 1+\epsilon]\)，即使同一批数据重复使用、ratio 偏离 1，超出部分会被截断，策略不会跳太远；KL 早停再兜一层底。多 epoch 复用本质是 " 在 clip 容忍范围内多走几步 "。
      • TRPO 的约束是 " 硬 " 的：它在当前策略处做二阶近似（Fisher 矩阵 + 共轭梯度），求解 \(KL(\pi_{old}\|\pi) \le \delta\) 的约束优化，理论上只保证单步更新后的单调改进。多次复用同一批数据后，importance ratio 严重偏离 1，二阶近似失效、约束可能被违反，理论保证不再成立。
      • 代价问题：TRPO 每次更新要算 Fisher-vector product，多次 epoch 计算昂贵；PPO 只需一阶梯度，复用数据几乎零额外成本。
      • 一句话：PPO 用 clip 换来了 " 可以糙一点、多走几步 "；TRPO 靠精确约束只能 " 小心走一步 "。

    2. 如果关掉优势归一化，会出现什么训练现象？

      • 梯度尺度随奖励尺度漂移：优势 \(A\) 的量级直接由 reward 和 \(V\) 的误差决定，奖励大的任务梯度爆炸、奖励小的任务梯度消失，需要针对任务手调 lr。
      • 训练曲线震荡、收敛变慢，严重时直接发散；policy loss 与 value loss 的尺度失衡（critic 的 MSE 天然比 policy loss 大 / 小几个量级时更明显）。
      • 对 reward 尺度敏感的任务影响最大（奖励范围大、稀疏奖励塑形后数值大）；reward 已在 \(O(1)\) 量级的简单任务（如 CartPole 每步 +1）影响较小，这也是很多 toy 例子不开归一化也能跑的原因。
      • 归一化相当于给优势做 " 自适应 lr"，让不同任务、不同训练阶段的更新幅度可比。

    3. approx_kl 是有偏估计，为什么还能用做早停？它和精确 KL 差距在哪？

      • 早停只需要 " 是否显著超阈值 " 的可靠信号，不需要精确值：KL 早停是安全阀，判断 " 策略是不是走太远了 "，一个方向正确、方差小的近似量足够。
      • 小 KL 时近似很准：当新旧策略接近，\(\log r \approx 0\)，有 \(e^{\log r}-1-\log r \approx \frac{1}{2}(\log r)^2\)，与精确 KL 同阶，近似误差可忽略。
      • 方差比直接 mean(log_ratio) 小：\(\log r\) 可正可负会相互抵消，而 \(e^{\log r}-1-\log r \ge 0\) 恒非负，对正负偏差都累积，估计更稳，不易被单步噪声误触发。
      • 与精确 KL 的差距：
        • 精确 KL 需要遍历所有动作（离散）或对连续分布积分，要拿到 old / new 两个完整分布；
        • approx_kl 只用采样到的动作的 log_ratio，便宜但只反映 " 采样分布下 " 的差异；
        • 策略变化大时一阶近似误差变大——但早停恰恰要在变化大时触发，此时近似虽不精确，方向仍一致（KL 大 → approx_kl 也大），足以做阈值判断。

    4. 熵正则在稀疏奖励任务里是帮助还是阻碍？

      • 适度熵正则是帮助：稀疏奖励早期几乎没有有效梯度，策略容易塌缩到某个动作后不再探索；熵正则维持动作多样性，帮助覆盖状态空间、撞到奖励信号，是稀疏奖励下常见的 " 续命 " 手段。
      • 过大熵正则是有害的：系数太大会让策略长期保持接近均匀随机，即便找到奖励也无法收敛到利用策略，表现为 reward 长期上不去、entropy 居高不下。
      • 实践结论：
        • 稀疏奖励常用熵退火（早期大、后期小到 0），兼顾探索与利用；
        • 单纯靠熵正则往往不够，常配合内在奖励（count-based、curiosity、RND）或奖励塑形；
        • 稀疏奖励下 critic 也难学，熵正则能防止 actor 在 critic 不准时过早塌缩，但无法替代更好的价值估计。
      • 一句话：稀疏奖励里熵正则是 " 必要的拐杖 "，但要会退火，过犹不及。

    11. 关键实现细节精讲 ¶

    11.1 优势归一化 ¶

    在每个 minibatch 内对优势做 z-normalization：

    A = (A - A.mean()) / (A.std() + 1e-8)

    两种主流落点，二选一，不要混用：

    方案 做法 代表实现 特点
    整批 rollout 归一 rollout 结束后、多 epoch 训练前，对全部 \(T \times n_{envs}\) 个优势统一做一次 SB3 原版 PPO 各 minibatch 优势尺度一致，跨 epoch 可比；实现最简单
    minibatch 内归一 每个 minibatch 送进 loss 前单独做一次 部分教学实现 / 早期论文复现 每个小批自适应尺度，对优势分布漂移更鲁棒；但批小时统计量噪声大
    • 本笔记实现采用的是整批归一（见第 6 节 train() 中在 epoch 循环外执行）。
    • 共同目的：消除奖励尺度对有效步长的影响——优势量级直接决定 policy loss 梯度量级，不做归一相当于 lr 随任务奖励尺度漂移。
    • 坑点提醒：不要在 loss 内部再对 advantages 归一化一次；归一化必须在计算 policy / value loss 之前一次性完成。

    11.2 多 epoch 小批量更新与 KL 早停 ¶

    • 标准 PPO 训练循环：

      1. 用 \(\pi_{\theta_{\text{old}}}\) 收集 \(N\) 条 rollout，计算 GAE 优势；
      2. 冻结 \(\theta_{\text{old}}\)，将数据打乱分成 minibatch；
      3. 对同一批数据做 \(K\) 个 epoch（典型 \(K=3\sim10\)）的 minibatch SGD/Adam 更新；

      4. 每个 epoch 结束后计算近似 KL：

        \[D_{\mathrm{KL}}\approx \mathbb{E}\left[e^{\log r}-1-\log r\right],\quad \log r = \log\pi_\theta - \log\pi_{\theta_{\text{old}}}\]

        （小 KL 时该式与一阶形式 \(\mathbb{E}[\log\pi_{\theta_{\text{old}}}-\log\pi_\theta]\) 同阶，但恒非负、方差更小，是本实现采用的写法）

      5. 若近似 KL 超过目标值的约 \(1.5\) 倍（或直接超过 target_kl，本实现用的是后者，见第 6 节），提前终止剩余 epoch，丢弃当前数据，重新采样。

    • 多 epoch 复用的收益来自样本利用率；代价是 ratio 逐渐偏离 1，clip 只能兜底、不能保证理论单调改进（对比 TRPO，见第 10 节第 1 题）。

    • KL 早停是 PPO 中防止“多 epoch 复用导致策略漂移过大”的最后一道防线，尤其在 LLM RLHF 中至关重要——RLHF 里一次 rollout 极贵，宁可早停也不能让策略崩掉。
    • 阈值口径差异：mean_epoch_kl > target_kl 与 > 1.5 * target_kl 都常见，前者更保守、后者防单批噪声误触发。

    11.3 价值函数与梯度裁剪 ¶

    • 价值损失：通常用 \(L_V=\mathbb{E}\left[(V_\phi(s_t)-\hat R_t)^2\right]\)，其中 \(\hat R_t=\hat A_t+V_{\phi_{\text{old}}}(s_t)\) 是价值目标（即 λ-return，本实现在 buffer 中存为 returns）。

    • 价值裁剪（可选）：将 \(V_\phi(s_t)\) 裁剪到 \(V_{\phi_{\text{old}}}(s_t)\pm \epsilon_v\) 再计算平方损失，防止 critic 单步跳变。

      values_clipped = old_values + torch.clamp(values - old_values, -clip_range_vf, clip_range_vf)
value_loss = torch.max(F.mse_loss(returns, values), F.mse_loss(returns, values_clipped))
      • SB3 的关键细节是取两个 MSE 的 max，而不是只用裁剪后的 loss——否则 critic 可以靠“贴着旧值不动”来偷懒降低 loss。
      • 效果有争议：部分任务（尤其 critic 本身拟合不稳时）有效，部分任务反而拖慢价值收敛；默认关闭，需消融验证（本实现 clip_range_vf=None 即关闭）。

    • 全局梯度范数裁剪：\(\|\nabla\|_2\) 裁剪到 \(0.5\) 左右是常见配置。（本实现 max_grad_norm=0.5）；注意是全局范数，不是逐元素或逐层。

    11.4 其他高影响细节 ¶

    • 正交初始化：策略网络最后一层使用小增益（约 \(0.01\)）的正交初始化，使初始 logits 接近 0、策略接近均匀分布、初始熵高；价值头用 gain \(=1.0\)，隐藏层用 \(\sqrt{2}\) 适配 Tanh。

      • 作用：早期策略梯度信号平稳、与 clip 配合首次更新不会跳太远（详见第 3 节）。

    • 学习率退火：训练过程中将学习率线性退火到零。；OpenAI 原版 PPO 标配，防止后期固定 lr 导致策略在最优附近震荡。

    • 观测归一化：在连续控制中，维护观测的运行均值 / 方差并做归一化，经常是“能解”与“不能解”的分界线。

    • 奖励归一化：对折扣回报（return）维护运行均值 / 方差并归一化，进一步稳定价值尺度。

      • 它与优势归一化目的重叠但作用对象不同：前者塑形奖励 / 回报，后者缩放训练信号。同时开启时效果会叠加，且 reward 归一化会改变最优价值尺度、需要谨慎。

    • 熵系数：离散控制中通常需要小的正熵奖励（\(c_2\sim 0.01\)），过大反而阻碍收敛、甚至让策略永远随机；连续控制常设为 0 或更小（见第 8 节第 6 条）。
