    强化学习 - PPO 的实现 ¶

    约 3041 个字 1494 行代码 预计阅读时间 29 分钟

    本篇为强化学习系列 番外篇：PPO 的实现 承接TRPO与PPO；在许多场景中，PPO仍然是强化学习的主力算法：它实现相对直接、样本效率与稳定性之间比较平衡，也足够容易扩展到并行环境和复杂动作空间。 PPO 的损失函数只有一行，但“PPO 能工作”在很大程度上依赖论文正文中几乎不提的实现细节。Engstrom 等人的系统性消融表明：有 Clip 但缺少关键工程细节的 PPO，往往不如有工程细节但使用朴素惩罚的版本 你可以把它看作是对前文 TRPO/PPO 理论的落地补充：既关心“为什么这样写”，也关心“实际写的时候要注意什么”

    0. 前置回顾：¶

    PPO-Clip 总损失公式：

    \[ L^{CLIP+V+S}=\mathbb{E}\left[ \min\left( r_t A_t,\; \mathrm{clip}(r_t,1-\epsilon,1+\epsilon)A_t \right) - c_v \mathcal{L}_t^{VF}(\theta) + c_s \cdot S[\pi_\theta(\cdot|s_t)] \right] \]

    其中

    \[r_t=\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}\]
    • \(\epsilon\)：clip 系数，通常为 0.2
    • \(c_v\)：价值损失权重，通常为 0.5
    • \(c_s\)：熵正则系数，通常为 0.01

      注意符号：熵是加项，最大化熵等价于鼓励探索；代码里 loss 是最小化，因此 loss 里是减项

    GAE 广义优势估计 :

    \[A_t^{GAE(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l \delta_{t+l},\quad \delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\]
    • \(\lambda=0\)：单步 TD 误差
    • \(\lambda=1\)：蒙特卡洛回报价值
    • 常用 \(\lambda=0.95,\gamma=0.99\)

    1. PPO 核心实现要点总览 ¶

    下面所有代码块都会绑定对应的实现要点，一一对应：

    1. Rollout 缓冲区 + GAE 优势计算：缓冲区存储交互轨迹，逆序递推 GAE；兼容多 env 维度，方便后续并行扩展
    2. Actor-Critic 共享网络：同时支持离散 Categorical、连续高斯 Normal 动作分布，策略头 + 价值头共享特征提取
    3. On-Policy 数据收集：on-policy 算法必须使用旧策略采集轨迹；支持观测 RunningMeanStd 归一化
    4. 优势归一化：本实现是整批 rollout 归一化（和 minibatch 归一化是两种主流方案，SB3 原版风格），消除奖励尺度影响
    5. 多 Epoch 复用数据 + KL 早停：同一批轨迹多次训练提升样本利用率；KL 超过阈值立刻终止本轮 epoch，防止策略漂移过大
    6. 价值裁剪（可选）：SB3 风格价值裁剪，限制 critic 单次更新的跳动幅度
    7. 梯度全局裁剪：约束参数梯度二范数，防止梯度爆炸
    8. 调度器支持：学习率、clip 范围支持可调用函数，实现线性退火
    9. 熵正则：熵损失加入总 loss，鼓励策略保持探索性
    10. 保存与加载：同时保存网络、优化器、观测归一化统计量，支持断点续训

    1.2 工具类观测归一化RunningMeanStd ¶

    # ==================== 1. 在线观测归一化 ====================
class RunningMeanStd:
    """
    维护运行均值和方差，用于对观测做白化。
    只在训练时更新统计量；评估/推理时固定使用训练得到的统计量。
    """
    def __init__(self, shape: Tuple[int, ...], epsilon: float = 1e-4):
        self.mean = np.zeros(shape, dtype=np.float32)
        self.var = np.ones(shape, dtype=np.float32)
        self.count = epsilon

    def update(self, x: np.ndarray):
        """x 形状: (batch, obs_dim)"""
        batch_mean = np.mean(x, axis=0)
        batch_var = np.var(x, axis=0)
        batch_count = x.shape[0]
        self._update_from_moments(batch_mean, batch_var, batch_count)

    def _update_from_moments(self, batch_mean, batch_var, batch_count):
        delta = batch_mean - self.mean
        total_count = self.count + batch_count
        new_mean = self.mean + delta * batch_count / total_count
        m_a = self.var * self.count
        m_b = batch_var * batch_count
        m_2 = m_a + m_b + np.square(delta) * self.count * batch_count / total_count
        new_var = m_2 / total_count
        new_count = total_count
        self.mean, self.var, self.count = new_mean, new_var, new_count

    2. Rollout Buffer¶

    • 实现要点：
      1. 数组预留 (T, n_envs, ...) 维度，天然支持多环境并行扩展，当前单环境也兼容
      2. compute_returns_and_advantages：逆序循环实现 GAE，用1-done掩码截断 episode，终止状态之后不传播价值
      3. _flatten：把(T, n_envs, ...)展平为(T*n_envs, ...)，方便 minibatch 采样
      4. get生成器：打乱索引，迭代输出 mini-batch，训练阶段取用
      5. 缓冲区同时缓存old_log_prob、old_values，是旧策略的固定值，训练时用来算重要性采样比率
    # ==================== 2. Rollout Buffer ====================
class RolloutBuffer:
    """
    存储一条或多条 rollout 的 (s,a,r,done,V,log_prob)，
    并负责计算 GAE 优势与回报。
    本版本默认单环境（n_envs=1），但数组维度保留了 n_envs，便于扩展。
    """
    def __init__(
        self,
        buffer_size: int,
        observation_space: gym.Space,
        action_space: gym.Space,
        device: Union[torch.device, str] = "cpu",
        n_envs: int = 1,
        gamma: float = 0.99,
        gae_lambda: float = 0.95,
    ):
        self.buffer_size = buffer_size
        self.obs_shape = observation_space.shape
        self.device = device
        self.n_envs = n_envs
        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.pos = 0

        # 根据动作空间类型决定动作数组形状
        if isinstance(action_space, gym.spaces.Discrete):
            self.action_shape = ()
            self.action_dtype = np.int64
        elif isinstance(action_space, gym.spaces.Box):
            self.action_shape = action_space.shape
            self.action_dtype = np.float32
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

        self.reset()

    def reset(self):
        self.observations = np.zeros((self.buffer_size, self.n_envs, *self.obs_shape), dtype=np.float32)
        self.actions = np.zeros((self.buffer_size, self.n_envs, *self.action_shape), dtype=self.action_dtype)
        self.rewards = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.dones = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.values = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.log_probs = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.advantages = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.returns = np.zeros((self.buffer_size, self.n_envs), dtype=np.float32)
        self.pos = 0

    def add(self, obs, action, reward, done, value, log_prob):
        self.observations[self.pos] = np.asarray(obs, dtype=np.float32).copy()
        self.actions[self.pos] = np.asarray(action, dtype=self.action_dtype).copy()
        self.rewards[self.pos] = np.asarray(reward, dtype=np.float32).copy()
        self.dones[self.pos] = np.asarray(done, dtype=np.float32).copy()
        self.values[self.pos] = np.asarray(value, dtype=np.float32).copy()
        self.log_probs[self.pos] = np.asarray(log_prob, dtype=np.float32).copy()
        self.pos += 1

    def compute_returns_and_advantages(self, last_values: np.ndarray, dones: np.ndarray):
        """
        GAE 计算。last_values: V(s_T)；dones: 最后一步的 done 标志。
        """
        last_gae_lam = np.zeros(self.n_envs, dtype=np.float32)
        T = self.pos
        for step in reversed(range(T)):
            if step == T - 1:
                next_non_terminal = 1.0 - dones
                next_values = last_values
            else:
                next_non_terminal = 1.0 - self.dones[step + 1]
                next_values = self.values[step + 1]

            delta = self.rewards[step] + self.gamma * next_values * next_non_terminal - self.values[step]
            last_gae_lam = delta + self.gamma * self.gae_lambda * next_non_terminal * last_gae_lam
            self.advantages[step] = last_gae_lam

        self.returns[:T] = self.advantages[:T] + self.values[:T]

    def get(self, batch_size: int):
        """打乱后按 mini-batch 产出训练数据"""
        assert self.pos > 0, "Rollout buffer 为空"

        obs = self._flatten(self.observations[: self.pos])
        actions = self._flatten(self.actions[: self.pos])
        old_values = self._flatten(self.values[: self.pos])
        old_log_prob = self._flatten(self.log_probs[: self.pos])
        advantages = self._flatten(self.advantages[: self.pos])
        returns = self._flatten(self.returns[: self.pos])

        indices = np.arange(obs.shape[0])
        np.random.shuffle(indices)

        for start in range(0, len(indices), batch_size):
            end = start + batch_size
            idx = indices[start:end]
            yield (
                torch.as_tensor(obs[idx], device=self.device),
                torch.as_tensor(actions[idx], device=self.device),
                torch.as_tensor(old_values[idx], device=self.device),
                torch.as_tensor(old_log_prob[idx], device=self.device),
                torch.as_tensor(advantages[idx], device=self.device),
                torch.as_tensor(returns[idx], device=self.device),
            )

    def _flatten(self, arr: np.ndarray) -> np.ndarray:
        """把 (T, n_envs, ...) 摊平成 (T*n_envs, ...)"""
        return arr.reshape(-1, *arr.shape[2:])

    3. Actor-Critic 网络 ¶

    • 对应实现要点：正交初始化

      • 策略网络 Actor 最后一层 / 输出层 使用小增益 ( 约 0.01) 的正交初始化，让权重非常小，使得初始 \(logits \approx 0\)，经过 softmax 后策略 接近均匀分布，每个动作概率 约为 1/A

      • 好处：

        • 鼓励初期探索，不会一上来就锁定某个动作
        • 早期策略梯度信号小且平稳，避免因随机初始化导致策略立刻崩溃
        • 与 PPO 的 clip_ratio 配合，使首次更新时新旧策略差异不会过大

      • 目标网络 Critic 目标是拟合回报，不需要抑制初始输出，用标准 gain=1.0 即可保证梯度方差在层间稳定传递

      • 正交初始化本身的作用：让每层输入 - 输出保持近似等距，缓解深层网络的梯度消失 / 爆炸

    • 实现要点：

      1. MLP 共享特征提取层，actor、critic 共享底层表示，减少参数量
      2. 双分支分布支持：离散动作Categorical，连续动作Normal高斯分布；连续动作使用可学习 log_std
      3. evaluate_actions：训练阶段专用接口，输入轨迹里固定的 action，计算新策略下 log_prob、entropy、value，用来算比率 \(r_t\)，不再采样动作（非常关键的坑点）
      4. predict推理接口：支持 deterministic 确定性输出，评估时关闭随机性；连续动作自动 clip 到环境合法区间
    # ==================== 3. Actor-Critic 策略网络 ====================
class ActorCritic(nn.Module):
    # 使用离散动作空间，适用离散任务
    def __init__(self, obs_dim, act_dim, hidden_dim=64):
        super().__init__()
        # Actor 和 Critic 共享特征提取网络：参数量更小、样本效率更高，任务梯度可能会相互干扰
        self.shared_net = nn.Sequential(
            nn.Linear(obs_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Tanh(),
        )
        # Actor head: 正交初始化。输出每个动作logit，不做softmax
        self.actor_head = nn.Linear(hidden_dim, act_dim)
        nn.init.orthogonal_(self.actor_head.weight, gain=0.01)
        nn.init.constant_(self.actor_head.bias, 0.)

        # Critic head: 正交初始化。输出状态价值V(s)
        self.critic_head = nn.Linear(hidden_dim, 1)
        nn.init.orthogonal_(self.critic_head.weight, gain=1.0)
        nn.init.constant_(self.critic_head.bias, 0.)

        for layer in self.shared_net:
            if isinstance(layer, nn.Linear):
                nn.init.orthogonal_(layer.weight, gain=np.sqrt(2))
                nn.init.constant_(layer.bias, 0.0)

    def get_action(self, obs):
        """收集rollout，采样动作"""
        feat = self.shared_net(obs)

        logits = self.actor_head(feat)
        dist = Categorical(logits=logits)

        action = dist.sample()
        log_prob = dist.log_prob(action)
        entropy = dist.entropy()

        value = self.critic_head(feat).squeeze(-1)
        return action, log_prob, entropy, value

    def evaluate(self, obs, action):
        """ 训练阶段使用，给定状态+动作，不做采样，只评估
        用于计算r_t = new_logprob / old_logprob"""
        feat = self.shared_net(obs)

        logits = self.actor_head(feat)
        dist = Categorical(logits=logits)

        log_prob = dist.log_prob(action)
        entropy = dist.entropy()

        value = self.critic_head(feat).squeeze(-1)
        return log_prob, entropy, value

class ActorCriticPolicy(nn.Module):
    """
    共享 MLP 特征提取层，分别输出策略分布和价值估计。
    支持 Discrete（Categorical）和 Box（Normal）两类动作空间。
    """
    def __init__(
        self,
        observation_space: gym.Space,
        action_space: gym.Space,
        hidden_sizes: Tuple[int, ...] = (64, 64),
        activation: Type[nn.Module] = nn.Tanh,
    ):
        super().__init__()
        self.observation_space = observation_space
        self.action_space = action_space

        obs_dim = int(np.prod(observation_space.shape))
        layers = []
        in_dim = obs_dim
        for h in hidden_sizes:
            layers.extend([nn.Linear(in_dim, h), activation()])
            in_dim = h
        self.mlp_extractor = nn.Sequential(*layers)
        self.latent_dim = in_dim

        # 价值头
        self.value_net = nn.Linear(self.latent_dim, 1)

        # 策略头
        if isinstance(action_space, gym.spaces.Discrete):
            self.action_dim = action_space.n
            self.action_net = nn.Linear(self.latent_dim, self.action_dim)
            self.dist_type = "categorical"
        elif isinstance(action_space, gym.spaces.Box):
            self.action_dim = action_space.shape[0]
            self.action_net = nn.Linear(self.latent_dim, self.action_dim)
            # 可学习的对数标准差
            self.log_std = nn.Parameter(torch.zeros(1, self.action_dim))
            self.dist_type = "normal"

            low = np.asarray(action_space.low, dtype=np.float32)
            high = np.asarray(action_space.high, dtype=np.float32)
            self.bounded = np.all(np.isfinite(low)) and np.all(np.isfinite(high))
            self.low = low
            self.high = high
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

    def forward(self, obs: torch.Tensor):
        features = self.mlp_extractor(obs)
        values = self.value_net(features).squeeze(-1)
        if self.dist_type == "categorical":
            logits = self.action_net(features)
            dist = Categorical(logits=logits)
        else:
            mean = self.action_net(features)
            dist = Normal(mean, self.log_std.exp().expand_as(mean))
        return dist, values

    def get_distribution(self, obs: torch.Tensor):
        return self.forward(obs)[0]

    def predict_values(self, obs: torch.Tensor):
        return self.forward(obs)[1]

    def evaluate_actions(self, obs: torch.Tensor, actions: torch.Tensor):
        """训练时评估：返回 V(s), log_pi(a|s), H(pi(s))"""
        dist, values = self.forward(obs)
        if self.dist_type == "categorical":
            log_prob = dist.log_prob(actions)
            entropy = dist.entropy()
        else:
            log_prob = dist.log_prob(actions).sum(dim=-1)
            entropy = dist.entropy().sum(dim=-1)
        return values, log_prob, entropy

    def predict(self, obs: torch.Tensor, deterministic: bool = False):
        """推理：返回 numpy 动作"""
        with torch.no_grad():
            dist = self.get_distribution(obs)
            if self.dist_type == "categorical":
                if deterministic:
                    action = torch.argmax(dist.probs, dim=-1)
                else:
                    action = dist.sample()
                return action.cpu().numpy()
            else:
                if deterministic:
                    action = dist.mean
                else:
                    action = dist.sample()
                action = action.cpu().numpy()
                if self.bounded:
                    action = np.clip(action, self.low, self.high)
                    return action

    4. 算法基类与 On-Policy 基类 ¶

    • 实现要点：
      1. BaseAlgorithm：通用 RL 算法抽象，封装随机种子、predict 对外推理接口
      2. OnPolicyAlgorithm：on-policy 专属父类，绑定 rollout buffer；on-policy 算法每一轮更新前必须重新采集轨迹，旧轨迹不能复用多轮 rollout
      3. collect_rollouts：策略 eval 模式下采集轨迹；支持 RunningMeanStd 在线更新观测均值方差；
        • 注意：存入 buffer 是原始未裁剪动作，环境 step 使用裁剪后的动作（连续空间保护环境）
      4. 采集结束后，预测最后一个状态的last_values，作为 GAE 的 bootstrap 目标 
        # ==================== 4. 算法基类与 On-Policy 基类 ====================
class BaseAlgorithm:
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module],
        learning_rate: Union[float, Callable] = 3e-4,
        n_steps: int = 2048,
        gamma: float = 0.99,
        gae_lambda: float = 0.95,
        ent_coef: float = 0.0,
        vf_coef: float = 0.5,
        max_grad_norm: float = 0.5,
        normalize_observations: bool = False,
        verbose: int = 0,
        seed: Optional[int] = None,
        device: Union[torch.device, str] = "auto",
    ):
        self.env = env
        self.policy_class = policy
        self.learning_rate = learning_rate
        self.n_steps = n_steps
        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.ent_coef = ent_coef
        self.vf_coef = vf_coef
        self.max_grad_norm = max_grad_norm
        self.normalize_observations = normalize_observations
        self.verbose = verbose
        self.seed = seed

        self.device = (
            torch.device("cuda" if torch.cuda.is_available() else "cpu")
            if device == "auto"
            else torch.device(device)
        )

        # 本版本为单环境实现
        self.n_envs = 1
        self.observation_space = env.observation_space
        self.action_space = env.action_space

        if isinstance(self.action_space, gym.spaces.Discrete):
            self.action_shape = ()
        elif isinstance(self.action_space, gym.spaces.Box):
            self.action_shape = self.action_space.shape
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

        self.num_timesteps = 0
        self._n_updates = 0
        self.ep_info_buffer = deque(maxlen=100)
        self._last_obs = None
        self.policy = None
        self.optimizer = None
        self.obs_rms = None

        if seed is not None:
            self.set_random_seed(seed)

        self._setup_model()

    def set_random_seed(self, seed: int):
        random.seed(seed)
        np.random.seed(seed)
        torch.manual_seed(seed)
        if torch.cuda.is_available():
            torch.cuda.manual_seed_all(seed)

    def _setup_model(self):
        raise NotImplementedError

    def predict(self, observation: np.ndarray, deterministic: bool = False):
        """对外接口：输入单步观测，输出动作"""
        obs = np.asarray(observation, dtype=np.float32)
        # 补 batch 维度
        if obs.ndim == len(self.observation_space.shape):
            obs = obs.reshape(1, *self.observation_space.shape)

        if self.obs_rms is not None:
            obs = self.obs_rms.normalize(obs.reshape(1, -1)).reshape(obs.shape).astype(np.float32)

        with torch.no_grad():
            action = self.policy.predict(torch.as_tensor(obs, device=self.device), deterministic=deterministic)
        return action[0]  # 去掉 batch 维度


class OnPolicyAlgorithm(BaseAlgorithm):
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module] = ActorCriticPolicy,
        rollout_buffer_class: Type[RolloutBuffer] = RolloutBuffer,
        **kwargs,
    ):
        super().__init__(env=env, policy=policy,** kwargs)
        self.rollout_buffer_class = rollout_buffer_class
        self.rollout_buffer = None

    def _setup_model(self):
        # 创建策略网络
        self.policy = self.policy_class(self.observation_space, self.action_space).to(self.device)

        # 可选观测归一化
        if self.normalize_observations:
            self.obs_rms = RunningMeanStd((int(np.prod(self.observation_space.shape)),))

        # 创建 rollout buffer
        self.rollout_buffer = self.rollout_buffer_class(
            self.n_steps,
            self.observation_space,
            self.action_space,
            device=self.device,
            n_envs=self.n_envs,
            gamma=self.gamma,
            gae_lambda=self.gae_lambda,
        )

    def collect_rollouts(self, env: gym.Env, total_timesteps: int):
        """
        采集 n_steps 条经验。若 total_timesteps 先到，则提前结束（支持最后一段不完整 rollout）。
        返回 (last_values, last_dones) 用于 GAE bootstrap。
        """
        self.rollout_buffer.reset()
        self.policy.eval()

        n_steps = 0
        last_dones = np.zeros(self.n_envs, dtype=np.float32)

        while n_steps < self.n_steps and self.num_timesteps < total_timesteps:
            raw_obs = self._last_obs  # shape: (1, obs_dim)

            # ---- 观测归一化 ----
            if self.obs_rms is not None:
                flat = raw_obs.reshape(self.n_envs, -1)
                self.obs_rms.update(flat)
                obs_input = self.obs_rms.normalize(flat).reshape(raw_obs.shape).astype(np.float32)
            else:
                obs_input = raw_obs

            obs_t = torch.as_tensor(obs_input, dtype=torch.float32, device=self.device)

            # ---- 采样动作 ----
            with torch.no_grad():
                dist = self.policy.get_distribution(obs_t)
                action_t = dist.sample()
                if self.policy.dist_type == "categorical":
                    log_prob_t = dist.log_prob(action_t)
                else:
                    log_prob_t = dist.log_prob(action_t).sum(dim=-1)
                value_t = self.policy.predict_values(obs_t)

            # 保存未裁剪动作到 buffer；环境 step 使用裁剪后的动作
            action_raw_np = action_t.cpu().numpy()
            if self.policy.dist_type == "normal" and self.policy.bounded:
                action_step_np = np.clip(action_raw_np, self.policy.low, self.policy.high)
            else:
                action_step_np = action_raw_np

            step_action = action_step_np[0]
            new_obs, reward, terminated, truncated, info = env.step(step_action)
            done = float(terminated or truncated)

            self.num_timesteps += 1
            self.rollout_buffer.add(
                obs_input,
                action_raw_np.reshape(self.n_envs, *self.action_shape),
                np.array([reward], dtype=np.float32),
                np.array([done], dtype=np.float32),
                value_t.cpu().numpy().reshape(self.n_envs),
                log_prob_t.cpu().numpy().reshape(self.n_envs),
            )

            # 记录回合回报（需要 env 被 Monitor 包装，或在 info 中提供 episode）
            if done > 0.5 and isinstance(info, dict) and "episode" in info:
                self.ep_info_buffer.append(info["episode"]["r"])

            # 单环境 done 后手动 reset
            if done > 0.5:
                new_obs, _ = env.reset()

            self._last_obs = np.asarray(new_obs, dtype=np.float32).reshape(self.n_envs, *self.observation_space.shape)
            n_steps += 1
            last_dones = np.array([done], dtype=np.float32)

        # ---- 计算最后状态的 V，用于 bootstrap ----
        last_obs = self._last_obs
        if self.obs_rms is not None:
            last_obs = self.obs_rms.normalize(last_obs.reshape(self.n_envs, -1)).reshape(last_obs.shape).astype(np.float32)

        with torch.no_grad():
            last_values = self.policy.predict_values(torch.as_tensor(last_obs, dtype=torch.float32, device=self.device))

        return last_values.cpu().numpy().reshape(self.n_envs), last_dones

    5. PPO 主类 ¶

    • 实现要点（全部 PPO 核心工程 trick 集中在此）
      1. 支持动态调度：learning_rate、clip_range可以传入函数，实现线性退火
      2. 优势归一化：normalize_advantage=True时，整批 rollout 统一做 z-score 归一（SB3 原版方案）
      3. PPO clip 策略损失：\(r_t=\exp(\log\pi_{new}-\log\pi_{old})\)，min(rA, clip®A)
      4. 可选价值裁剪clip_range_vf：SB3 经典实现，约束 critic 更新幅度，取两个 MSE 的最大值
      5. 熵损失：entropy_loss = -mean(entropy)，加到总 loss；最小化 loss 等价最大化熵，鼓励探索
      6. 全局梯度裁剪：clip_grad_norm_，上限max_grad_norm
      7. KL 早停：使用 \(\text{approx_kl}=E\left[ e^{\log r}-1-\log r \right]\)；epoch 内 KL 超过target_kl直接 break，停止本轮所有 epoch 更新
      8. TensorBoard 日志：记录 policy_loss、value_loss、熵、KL、lr、clip 范围
      9. learn主循环：标准流程：收集 rollout → 计算 GAE → train 更新，循环直到总 timestep 达标
      10. save/load：持久化包含 obs_rms 的均值方差，支持断点续训 
        # ==================== 5. PPO 主类 ====================
class PPO(OnPolicyAlgorithm):
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module] = ActorCriticPolicy,
        learning_rate: Union[float, Callable] = 3e-4,
        n_steps: int = 2048,
        batch_size: int = 64,
        n_epochs: int = 10,
        gamma: float = 0.99,
        gae_lambda: float = 0.95,
        clip_range: Union[float, Callable] = 0.2,
        clip_range_vf: Optional[Union[float, Callable]] = None,
        normalize_advantage: bool = True,
        ent_coef: float = 0.0,
        vf_coef: float = 0.5,
        max_grad_norm: float = 0.5,
        target_kl: Optional[float] = None,
        normalize_observations: bool = False,
        tensorboard_log: Optional[str] = None,
        verbose: int = 0,
        seed: Optional[int] = None,
        device: Union[torch.device, str] = "auto",
    ):
        super().__init__(
            env=env,
            policy=policy,
            learning_rate=learning_rate,
            n_steps=n_steps,
            gamma=gamma,
            gae_lambda=gae_lambda,
            ent_coef=ent_coef,
            vf_coef=vf_coef,
            max_grad_norm=max_grad_norm,
            normalize_observations=normalize_observations,
            verbose=verbose,
            seed=seed,
            device=device,
        )

        # PPO 特有超参数
        self.batch_size = batch_size
        self.n_epochs = n_epochs
        self.clip_range = clip_range
        self.clip_range_vf = clip_range_vf
        self.normalize_advantage = normalize_advantage
        self.target_kl = target_kl
        self.tensorboard_log = tensorboard_log
        self.writer = SummaryWriter(tensorboard_log) if tensorboard_log else None

        self._total_timesteps = 0  # 在 learn 时设置，用于 schedule

    # -------------------- 模型与工具函数 --------------------
    def _setup_model(self):
        """先调用父类创建 policy / buffer / obs_rms，再创建 Adam 优化器"""
        super()._setup_model()
        self.optimizer = optim.Adam(self.policy.parameters(), lr=self._get_lr(0.0))

    def _get_lr(self, progress: float) -> float:
        if callable(self.learning_rate):
            return self.learning_rate(progress)
        return float(self.learning_rate)

    def _get_clip_range(self, progress: float) -> float:
        if callable(self.clip_range):
            return self.clip_range(progress)
        return float(self.clip_range)

    def _get_clip_range_vf(self, progress: float) -> Optional[float]:
        if self.clip_range_vf is None:
            return None
        if callable(self.clip_range_vf):
            return self.clip_range_vf(progress)
        return float(self.clip_range_vf)

    def _get_constructor_parameters(self) -> Dict[str, Any]:
        """保存/加载时记录构造参数"""
        return dict(
            env=None,
            policy=self.policy_class,
            learning_rate=self.learning_rate,
            n_steps=self.n_steps,
            batch_size=self.batch_size,
            n_epochs=self.n_epochs,
            gamma=self.gamma,
            gae_lambda=self.gae_lambda,
            clip_range=self.clip_range,
            clip_range_vf=self.clip_range_vf,
            normalize_advantage=self.normalize_advantage,
            ent_coef=self.ent_coef,
            vf_coef=self.vf_coef,
            max_grad_norm=self.max_grad_norm,
            target_kl=self.target_kl,
            normalize_observations=self.normalize_observations,
            tensorboard_log=self.tensorboard_log,
            verbose=self.verbose,
            seed=self.seed,
            device=str(self.device),
        )

    # -------------------- 训练核心 --------------------
    def train(self):
        """
        使用 RolloutBuffer 中的数据进行 PPO 多 epoch 更新。
        包含：advantage 归一化、策略 clip、value clip（可选）、entropy、KL early stopping。
        """
        self.policy.train()

        # 当前训练进度，用于学习率 / clip range 的 schedule
        progress = self.num_timesteps / self._total_timesteps if self._total_timesteps > 0 else 0.0
        clip_range = self._get_clip_range(progress)
        clip_range_vf = self._get_clip_range_vf(progress)
        lr = self._get_lr(progress)

        # 手动更新学习率（不依赖 LambdaLR，避免 total_timesteps 未知的问题）
        for param_group in self.optimizer.param_groups:
            param_group["lr"] = lr

        # ---- 优势归一化（可选，整个 batch 做一次） ----
        if self.normalize_advantage:
            adv_flat = self.rollout_buffer.advantages[: self.rollout_buffer.pos].reshape(-1)
            adv_flat = (adv_flat - adv_flat.mean()) / (adv_flat.std() + 1e-8)
            self.rollout_buffer.advantages[: self.rollout_buffer.pos] = adv_flat.reshape(
                self.rollout_buffer.pos, self.n_envs
            )

        # 记录损失，用于日志
        entropy_losses, policy_losses, value_losses, approx_kl_divs = [], [], [], []
        continue_training = True

        # -------------------- 多 epoch 更新 --------------------
        for epoch in range(self.n_epochs):
            approx_kl_divs_epoch = []

            for rollout_data in self.rollout_buffer.get(self.batch_size):
                obs, actions, old_values, old_log_prob, advantages, returns = rollout_data

                # 重新评估当前策略下的 log_prob、熵、价值
                values, log_prob, entropy = self.policy.evaluate_actions(obs, actions)
                values = values.float()
                log_prob = log_prob.float()
                advantages = advantages.float()

                # ---- 策略损失（PPO-Clip） ----
                ratio = torch.exp(log_prob - old_log_prob)
                policy_loss_1 = advantages * ratio
                policy_loss_2 = advantages * torch.clamp(ratio, 1 - clip_range, 1 + clip_range)
                policy_loss = -torch.min(policy_loss_1, policy_loss_2).mean()

                # ---- 价值损失（可选 value clipping） ----
                if clip_range_vf is None:
                    value_loss = F.mse_loss(values, returns)
                else:
                    # SB3 风格：限制新 value 相对旧 value 的变化幅度，取 clip/不 clip 中较大者
                    values_clipped = old_values + torch.clamp(
                        values - old_values, -clip_range_vf, clip_range_vf
                    )
                    value_loss1 = F.mse_loss(returns, values)
                    value_loss2 = F.mse_loss(returns, values_clipped)
                    value_loss = torch.max(value_loss1, value_loss2)

                # ---- 熵奖励（鼓励探索） ----
                entropy_loss = -entropy.mean()

                # ---- 总损失与反向传播 ----
                loss = policy_loss + self.vf_coef * value_loss + self.ent_coef * entropy_loss

                self.optimizer.zero_grad()
                loss.backward()
                nn.utils.clip_grad_norm_(self.policy.parameters(), self.max_grad_norm)
                self.optimizer.step()

                # ---- 近似 KL，用于 early stopping ----
                with torch.no_grad():
                    log_ratio = log_prob - old_log_prob
                    approx_kl = torch.mean((torch.exp(log_ratio) - 1) - log_ratio).item()
                    approx_kl_divs_epoch.append(approx_kl)

                policy_losses.append(policy_loss.item())
                value_losses.append(value_loss.item())
                entropy_losses.append(entropy_loss.item())

            mean_epoch_kl = np.mean(approx_kl_divs_epoch)
            approx_kl_divs.append(mean_epoch_kl)

            # KL 超过阈值则提前结束所有 epoch
            if self.target_kl is not None and mean_epoch_kl > self.target_kl:
                if self.verbose > 0:
                    print(
                        f"  [early stop] epoch {epoch + 1}/{self.n_epochs}, "
                        f"KL={mean_epoch_kl:.5f} > target_kl={self.target_kl:.5f}"
                    )
                continue_training = False
                break

        self._n_updates += 1

        # -------------------- TensorBoard 日志 --------------------
        if self.writer is not None:
            self.writer.add_scalar("train/policy_loss", np.mean(policy_losses), self._n_updates)
            self.writer.add_scalar("train/value_loss", np.mean(value_losses), self._n_updates)
            self.writer.add_scalar("train/entropy_loss", np.mean(entropy_losses), self._n_updates)
            self.writer.add_scalar("train/approx_kl", np.mean(approx_kl_divs), self._n_updates)
            self.writer.add_scalar("train/clip_range", clip_range, self._n_updates)
            self.writer.add_scalar("train/lr", lr, self._n_updates)

    # -------------------- 主学习循环 --------------------
    def learn(self, total_timesteps: int, log_interval: int = 1):
        """
        主入口：反复收集 rollout -> 计算 GAE -> train()，直到达到 total_timesteps。
        """
        self._total_timesteps = total_timesteps
        self._start_time = time.time()

        # 初始化环境
        obs, _ = self.env.reset()
        self._last_obs = np.asarray(obs, dtype=np.float32).reshape(
            self.n_envs, *self.observation_space.shape
        )

        while self.num_timesteps < total_timesteps:
            # ---- 1. 收集 rollout ----
            last_values, last_dones = self.collect_rollouts(self.env, total_timesteps)

            if self.rollout_buffer.pos == 0:
                break

            # ---- 2. 计算 GAE 优势和回报 ----
            self.rollout_buffer.compute_returns_and_advantages(last_values, last_dones)

            # ---- 3. 更新策略 ----
            self.train()

            # ---- 4. 打印日志 ----
            if self.verbose > 0 and self._n_updates % log_interval == 0:
                elapsed = time.time() - self._start_time
                fps = int(self.num_timesteps / elapsed) if elapsed > 0 else 0
                mean_reward = (
                    np.mean(list(self.ep_info_buffer)) if len(self.ep_info_buffer) > 0 else -np.inf
                )
                print(
                    f"updates={self._n_updates:4d} | "
                    f"steps={self.num_timesteps:7d} | "
                    f"fps={fps:4d} | "
                    f"mean_reward(last100)={mean_reward:.2f}"
                )
                if self.writer is not None:
                    self.writer.add_scalar("rollout/ep_rew_mean", mean_reward, self.num_timesteps)

        if self.writer is not None:
            self.writer.close()

        return self

    # -------------------- 保存 / 加载 --------------------
    def save(self, path: str):
        """保存模型参数、优化器、观测归一化统计量和训练进度"""
        os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
        data = {
            "policy_state_dict": self.policy.state_dict(),
            "optimizer_state_dict": self.optimizer.state_dict(),
            "hyperparams": self._get_constructor_parameters(),
            "num_timesteps": self.num_timesteps,
            "_n_updates": self._n_updates,
        }
        if self.obs_rms is not None:
            data["obs_rms"] = {
                "mean": self.obs_rms.mean,
                "var": self.obs_rms.var,
                "count": self.obs_rms.count,
            }
        else:
            data["obs_rms"] = None

        torch.save(data, path)
        if self.verbose > 0:
            print(f"[save] {path}")

    @classmethod
    def load(cls, path: str, env: gym.Env, device: Union[torch.device, str] = "auto"):
        """
        从 save 文件恢复模型。需要传入新的 env（也可以把 env 存入 hyperparams 恢复）。
        """
        data = torch.load(path, map_location="cpu")
        hyperparams = data["hyperparams"]
        hyperparams["env"] = env
        hyperparams["device"] = device

        model = cls(**hyperparams)
        model.policy.load_state_dict(data["policy_state_dict"])
        model.optimizer.load_state_dict(data["optimizer_state_dict"])

        if data["obs_rms"] is not None:
            model.obs_rms.mean = data["obs_rms"]["mean"]
            model.obs_rms.var = data["obs_rms"]["var"]
            model.obs_rms.count = data["obs_rms"]["count"]

        model.num_timesteps = data.get("num_timesteps", 0)
        model._n_updates = data.get("_n_updates", 0)
        return model

    1. 旧策略参数一定不能在更新中被修改 old_logp / old_value 全部在rollout收集阶段torch.no_grad()下算出；更新时只拿它们做比值，不要重新计算旧logp。

    2. 优势归一化是 minibatch 内，不是整个 rollout 很多新手直接对整段A归一，效果会差很多。

    3. GAE 反向遍历，done 位置截断价值 终止状态 \(s_T\) 之后没有价值，next_value=0；不处理done会把跨episode的价值混在一起，优势完全错误。

    4. KL 是监控信号，不是损失项 很多新手误把KL加到loss里，那就变成带KL惩罚的PPO（PPO-Penalty），不是原生Clip-PPO；RLHF里的KL惩罚是另外一套。

    5. 梯度裁剪是对网络全部参数的全局范数，不是单独裁剪每层梯度 nn.utils.clip_grad_norm_，不是clip_grad_value_。

    6. 熵系数不要太大 CartPole这类简单任务0.01足够；太大熵鼓励随机探索，永远不收敛。连续任务有时熵系数要更小甚至0。

    7. 学习率退火：线性衰减到 0 固定学习率后期容易震荡，这是OpenAI原版PPO标配。

    8. 分布数值稳定性 exp(logp_new - logp_old) 求ratio，不要直接存概率做除法，防止数值下溢。

    补充说明 & 踩坑清单 ¶

    1. 优势归一化：本实现是整 rollout 批次归一；另一种主流方案是 minibatch 内归一，二者都是有效的工程选择，SB3 原版使用整批归一
    2. KL 计算公式：这里使用 \(KL \approx E\left[ e^{\log r}-1-\log r \right]\)，是 PPO 论文常用的一阶近似，不是精确 KL
    3. 连续动作：log_std 为全局可学习参数；也可以改成网络输出 log_std，根据任务选择
    4. 观测归一化：连续控制（MuJoCo、SUMO 交通）强烈建议开启；CartPole 这类离散简单环境可关闭
    5. value clip 默认关闭，属于可选 trick，部分任务会不稳定，需要消融实验验证
    6. 熵系数ent_coef：离散任务一般 0.01；连续控制经常设置为 0，防止探索爆炸
    7. on-policy 约束：每一次 train 之前必须重新 collect rollout，旧轨迹不能跨 rollout 重复使用

    8. 可选扩展与进阶改造方向（笔记拓展区）¶

    • 连续动作：把Categorical换成Normal，网络输出均值 +logstd，注意 logstd 单独参数或者共享；clip 要在分布域而不是动作域
    • 并行向量化环境：gym.vector，一次收集多环境 rollout，大幅提速
    • 价值裁剪：在ppo_update里增加v_clipped = old_val + torch.clamp(curr_val - old_val, -clip_v, clip_v)，二选一计算 value loss 取最大值
    • 运行时观测归一化：维护RunningMeanStd，对 obs 做归一，连续控制必备
    • 多 GPU：DDP/FSDP，rollout 收集在每个进程独立做，更新 all-reduce 梯度

## 0. PPO实现要点

### 3.1 优势归一化

在每个 minibatch 内对优势做 z-normalization：
```python
A = (A - A.mean()) / (A.std() + 1e-8)
      注意是按 minibatch 归一化，而不是对整批 rollout 全局归一化。这消除了奖励尺度对有效步长的影响，是单项效应最大的实现细节之一。

    3.2 多 epoch 小批量更新与 KL 早停 ¶

    标准 PPO 训练循环：

    1. 用 \(\pi_{\theta_{\text{old}}}\) 收集 \(N\) 条 rollout，计算 GAE 优势；
    2. 冻结 \(\theta_{\text{old}}\)，将数据打乱分成 minibatch；
    3. 对同一批数据做 \(K\) 个 epoch（典型 \(K=3\sim10\)）的 minibatch SGD/Adam 更新；
    4. 每个 epoch 结束后计算近似 KL \(D_{\mathrm{KL}}\approx \mathbb{E}[\log \pi_{\theta_{\text{old}}}-\log \pi_\theta]\)；
    5. 若近似 KL 超过目标值的约 \(1.5\) 倍，提前终止剩余 epoch，丢弃当前数据，重新采样。

    KL 早停是 PPO 中防止“多 epoch 复用导致策略漂移过大”的最后一道防线，尤其在 LLM RLHF 中至关重要。

    3.3 价值函数与梯度裁剪 ¶

    • 价值损失：通常用 \(L_V=\mathbb{E}[(V_\phi(s_t)-\hat R_t)^2]\)，其中 \(\hat R_t=\hat A_t+V_{\phi_{\text{old}}}(s_t)\) 是价值目标。
    • 价值裁剪（可选）：将 \(V_\phi(s_t)\) 裁剪到 \(V_{\phi_{\text{old}}}(s_t)\pm \epsilon_v\) 再计算平方损失，防止 critic 单步跳变。这一技巧的效果有争议，需在具体任务上验证。
    • 全局梯度范数裁剪：\(\|\nabla\|_2\) 裁剪到 \(0.5\) 左右是常见配置。

    3.4 其他高影响细节 ¶

    • 正交初始化：策略网络最后一层使用小增益（约 \(0.01\)）的正交初始化，使初始策略接近均匀、高熵。
    • 学习率退火：训练过程中将学习率线性退火到零。
    • 观测 / 奖励归一化：在连续控制中，维护观测和折扣回报的运行均值 / 方差并做归一化，经常是“能解”与“不能解”的分界线。
    • 熵系数：离散控制中通常需要小的正熵奖励（\(c_2\sim 0.01\)），过大反而阻碍收敛。

class ActorCriticPolicy(nn.Module):
    """
    共享 MLP 特征提取层，分别输出策略分布和价值估计。
    支持 Discrete（Categorical）和 Box（Normal）两类动作空间。
    """
    def __init__(
        self,
        observation_space: gym.Space,
        action_space: gym.Space,
        hidden_sizes: Tuple[int, ...] = (64, 64),
        activation: Type[nn.Module] = nn.Tanh,
    ):
        super().__init__()
        self.observation_space = observation_space
        self.action_space = action_space

        obs_dim = int(np.prod(observation_space.shape))
        layers = []
        in_dim = obs_dim
        for h in hidden_sizes:
            layers.extend([nn.Linear(in_dim, h), activation()])
            in_dim = h
        self.mlp_extractor = nn.Sequential(*layers)
        self.latent_dim = in_dim

        # 价值头
        self.value_net = nn.Linear(self.latent_dim, 1)

        # 策略头
        if isinstance(action_space, gym.spaces.Discrete):
            self.action_dim = action_space.n
            self.action_net = nn.Linear(self.latent_dim, self.action_dim)
            self.dist_type = "categorical"
        elif isinstance(action_space, gym.spaces.Box):
            self.action_dim = action_space.shape[0]
            self.action_net = nn.Linear(self.latent_dim, self.action_dim)
            # 可学习的对数标准差
            self.log_std = nn.Parameter(torch.zeros(1, self.action_dim))
            self.dist_type = "normal"

            low = np.asarray(action_space.low, dtype=np.float32)
            high = np.asarray(action_space.high, dtype=np.float32)
            self.bounded = np.all(np.isfinite(low)) and np.all(np.isfinite(high))
            self.low = low
            self.high = high
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

    def forward(self, obs: torch.Tensor):
        features = self.mlp_extractor(obs)
        values = self.value_net(features).squeeze(-1)
        if self.dist_type == "categorical":
            logits = self.action_net(features)
            dist = Categorical(logits=logits)
        else:
            mean = self.action_net(features)
            dist = Normal(mean, self.log_std.exp().expand_as(mean))
        return dist, values

    def get_distribution(self, obs: torch.Tensor):
        return self.forward(obs)[0]

    def predict_values(self, obs: torch.Tensor):
        return self.forward(obs)[1]

    def evaluate_actions(self, obs: torch.Tensor, actions: torch.Tensor):
        """训练时评估：返回 V(s), log_pi(a|s), H(pi(s))"""
        dist, values = self.forward(obs)
        if self.dist_type == "categorical":
            log_prob = dist.log_prob(actions)
            entropy = dist.entropy()
        else:
            log_prob = dist.log_prob(actions).sum(dim=-1)
            entropy = dist.entropy().sum(dim=-1)
        return values, log_prob, entropy

    def predict(self, obs: torch.Tensor, deterministic: bool = False):
        """推理：返回 numpy 动作"""
        with torch.no_grad():
            dist = self.get_distribution(obs)
            if self.dist_type == "categorical":
                if deterministic:
                    action = torch.argmax(dist.probs, dim=-1)
                else:
                    action = dist.sample()
                return action.cpu().numpy()
            else:
                if deterministic:
                    action = dist.mean
                else:
                    action = dist.sample()
                action = action.cpu().numpy()
                if self.bounded:
                    action = np.clip(action, self.low, self.high)
                return action

class BaseAlgorithm:
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module],
        learning_rate: Union[float, Callable] = 3e-4,
        n_steps: int = 2048,
        gamma: float = 0.99,
        gae_lambda: float = 0.95,
        ent_coef: float = 0.0,
        vf_coef: float = 0.5,
        max_grad_norm: float = 0.5,
        normalize_observations: bool = False,
        verbose: int = 0,
        seed: Optional[int] = None,
        device: Union[torch.device, str] = "auto",
    ):
        self.env = env
        self.policy_class = policy
        self.learning_rate = learning_rate
        self.n_steps = n_steps
        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.ent_coef = ent_coef
        self.vf_coef = vf_coef
        self.max_grad_norm = max_grad_norm
        self.normalize_observations = normalize_observations
        self.verbose = verbose
        self.seed = seed

        self.device = (
            torch.device("cuda" if torch.cuda.is_available() else "cpu")
            if device == "auto"
            else torch.device(device)
        )

        # 本版本为单环境实现
        self.n_envs = 1
        self.observation_space = env.observation_space
        self.action_space = env.action_space

        if isinstance(self.action_space, gym.spaces.Discrete):
            self.action_shape = ()
        elif isinstance(self.action_space, gym.spaces.Box):
            self.action_shape = self.action_space.shape
        else:
            raise NotImplementedError("仅支持 Discrete / Box 动作空间")

        self.num_timesteps = 0
        self._n_updates = 0
        self.ep_info_buffer = deque(maxlen=100)
        self._last_obs = None
        self.policy = None
        self.optimizer = None
        self.obs_rms = None

        if seed is not None:
            self.set_random_seed(seed)

        self._setup_model()

    def set_random_seed(self, seed: int):
        random.seed(seed)
        np.random.seed(seed)
        torch.manual_seed(seed)
        if torch.cuda.is_available():
            torch.cuda.manual_seed_all(seed)

    def _setup_model(self):
        raise NotImplementedError

    def predict(self, observation: np.ndarray, deterministic: bool = False):
        """对外接口：输入单步观测，输出动作"""
        obs = np.asarray(observation, dtype=np.float32)
        # 补 batch 维度
        if obs.ndim == len(self.observation_space.shape):
            obs = obs.reshape(1, *self.observation_space.shape)

        if self.obs_rms is not None:
            obs = self.obs_rms.normalize(obs.reshape(1, -1)).reshape(obs.shape).astype(np.float32)

        with torch.no_grad():
            action = self.policy.predict(torch.as_tensor(obs, device=self.device), deterministic=deterministic)
        return action[0]  # 去掉 batch 维度


class OnPolicyAlgorithm(BaseAlgorithm):
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module] = ActorCriticPolicy,
        rollout_buffer_class: Type[RolloutBuffer] = RolloutBuffer,
        **kwargs,
    ):
        super().__init__(env=env, policy=policy, **kwargs)
        self.rollout_buffer_class = rollout_buffer_class
        self.rollout_buffer = None

    def _setup_model(self):
        # 创建策略网络
        self.policy = self.policy_class(self.observation_space, self.action_space).to(self.device)

        # 可选观测归一化
        if self.normalize_observations:
            self.obs_rms = RunningMeanStd((int(np.prod(self.observation_space.shape)),))

        # 创建 rollout buffer
        self.rollout_buffer = self.rollout_buffer_class(
            self.n_steps,
            self.observation_space,
            self.action_space,
            device=self.device,
            n_envs=self.n_envs,
            gamma=self.gamma,
            gae_lambda=self.gae_lambda,
        )

    def collect_rollouts(self, env: gym.Env, total_timesteps: int):
        """
        采集 n_steps 条经验。若 total_timesteps 先到，则提前结束（支持最后一段不完整 rollout）。
        返回 (last_values, last_dones) 用于 GAE bootstrap。
        """
        self.rollout_buffer.reset()
        self.policy.eval()

        n_steps = 0
        last_dones = np.zeros(self.n_envs, dtype=np.float32)

        while n_steps < self.n_steps and self.num_timesteps < total_timesteps:
            raw_obs = self._last_obs  # shape: (1, obs_dim)

            # ---- 观测归一化 ----
            if self.obs_rms is not None:
                flat = raw_obs.reshape(self.n_envs, -1)
                self.obs_rms.update(flat)
                obs_input = self.obs_rms.normalize(flat).reshape(raw_obs.shape).astype(np.float32)
            else:
                obs_input = raw_obs

            obs_t = torch.as_tensor(obs_input, dtype=torch.float32, device=self.device)

            # ---- 采样动作 ----
            with torch.no_grad():
                dist = self.policy.get_distribution(obs_t)
                action_t = dist.sample()
                if self.policy.dist_type == "categorical":
                    log_prob_t = dist.log_prob(action_t)
                else:
                    log_prob_t = dist.log_prob(action_t).sum(dim=-1)
                value_t = self.policy.predict_values(obs_t)

            # 保存未裁剪动作到 buffer；环境 step 使用裁剪后的动作
            action_raw_np = action_t.cpu().numpy()
            if self.policy.dist_type == "normal" and self.policy.bounded:
                action_step_np = np.clip(action_raw_np, self.policy.low, self.policy.high)
            else:
                action_step_np = action_raw_np

            step_action = action_step_np[0]
            new_obs, reward, terminated, truncated, info = env.step(step_action)
            done = float(terminated or truncated)

            self.num_timesteps += 1
            self.rollout_buffer.add(
                obs_input,
                action_raw_np.reshape(self.n_envs, *self.action_shape),
                np.array([reward], dtype=np.float32),
                np.array([done], dtype=np.float32),
                value_t.cpu().numpy().reshape(self.n_envs),
                log_prob_t.cpu().numpy().reshape(self.n_envs),
            )

            # 记录回合回报（需要 env 被 Monitor 包装，或在 info 中提供 episode）
            if done > 0.5 and isinstance(info, dict) and "episode" in info:
                self.ep_info_buffer.append(info["episode"]["r"])

            # 单环境 done 后手动 reset
            if done > 0.5:
                new_obs, _ = env.reset()

            self._last_obs = np.asarray(new_obs, dtype=np.float32).reshape(self.n_envs, *self.observation_space.shape)
            n_steps += 1
            last_dones = np.array([done], dtype=np.float32)

        # ---- 计算最后状态的 V，用于 bootstrap ----
        last_obs = self._last_obs
        if self.obs_rms is not None:
            last_obs = self.obs_rms.normalize(last_obs.reshape(self.n_envs, -1)).reshape(last_obs.shape).astype(np.float32)

        with torch.no_grad():
            last_values = self.policy.predict_values(torch.as_tensor(last_obs, dtype=torch.float32, device=self.device))

        return last_values.cpu().numpy().reshape(self.n_envs), last_dones


# ==================== 5. PPO 主类 ====================
class PPO(OnPolicyAlgorithm):
    def __init__(
        self,
        env: gym.Env,
        policy: Type[nn.Module] = ActorCriticPolicy,
        learning_rate: Union[float, Callable] = 3e-4,
        n_steps: int = 2048,
        batch_size: int = 64,
        n_epochs: int = 10,
        gamma: float = 0.99,
        gae_lambda: float = 0.95,
        clip_range: Union[float, Callable] = 0.2,
        clip_range_vf: Optional[Union[float, Callable]] = None,
        normalize_advantage: bool = True,
        ent_coef: float = 0.0,
        vf_coef: float = 0.5,
        max_grad_norm: float = 0.5,
        target_kl: Optional[float] = None,
        normalize_observations: bool = False,
        tensorboard_log: Optional[str] = None,
        verbose: int = 0,
        seed: Optional[int] = None,
        device: Union[torch.device, str] = "auto",
    ):
        super().__init__(
            env=env,
            policy=policy,
            learning_rate=learning_rate,
            n_steps=n_steps,
            gamma=gamma,
            gae_lambda=gae_lambda,
            ent_coef=ent_coef,
            vf_coef=vf_coef,
            max_grad_norm=max_grad_norm,
            normalize_observations=normalize_observations,
            verbose=verbose,
            seed=seed,
            device=device,
        )

        # PPO 特有超参数
        self.batch_size = batch_size
        self.n_epochs = n_epochs
        self.clip_range = clip_range
        self.clip_range_vf = clip_range_vf
        self.normalize_advantage = normalize_advantage
        self.target_kl = target_kl
        self.tensorboard_log = tensorboard_log
        self.writer = SummaryWriter(tensorboard_log) if tensorboard_log else None

        self._total_timesteps = 0  # 在 learn 时设置，用于 schedule

    # -------------------- 模型与工具函数 --------------------
    def _setup_model(self):
        """先调用父类创建 policy / buffer / obs_rms，再创建 Adam 优化器"""
        super()._setup_model()
        self.optimizer = optim.Adam(self.policy.parameters(), lr=self._get_lr(0.0))

    def _get_lr(self, progress: float) -> float:
        if callable(self.learning_rate):
            return self.learning_rate(progress)
        return float(self.learning_rate)

    def _get_clip_range(self, progress: float) -> float:
        if callable(self.clip_range):
            return self.clip_range(progress)
        return float(self.clip_range)

    def _get_clip_range_vf(self, progress: float) -> Optional[float]:
        if self.clip_range_vf is None:
            return None
        if callable(self.clip_range_vf):
            return self.clip_range_vf(progress)
        return float(self.clip_range_vf)

    def _get_constructor_parameters(self) -> Dict[str, Any]:
        """保存/加载时记录构造参数"""
        return dict(
            env=None,
            policy=self.policy_class,
            learning_rate=self.learning_rate,
            n_steps=self.n_steps,
            batch_size=self.batch_size,
            n_epochs=self.n_epochs,
            gamma=self.gamma,
            gae_lambda=self.gae_lambda,
            clip_range=self.clip_range,
            clip_range_vf=self.clip_range_vf,
            normalize_advantage=self.normalize_advantage,
            ent_coef=self.ent_coef,
            vf_coef=self.vf_coef,
            max_grad_norm=self.max_grad_norm,
            target_kl=self.target_kl,
            normalize_observations=self.normalize_observations,
            tensorboard_log=self.tensorboard_log,
            verbose=self.verbose,
            seed=self.seed,
            device=str(self.device),
        )

    # -------------------- 训练核心 --------------------
    def train(self):
        """
        使用 RolloutBuffer 中的数据进行 PPO 多 epoch 更新。
        包含：advantage 归一化、策略 clip、value clip（可选）、entropy、KL early stopping。
        """
        self.policy.train()

        # 当前训练进度，用于学习率 / clip range 的 schedule
        progress = self.num_timesteps / self._total_timesteps if self._total_timesteps > 0 else 0.0
        clip_range = self._get_clip_range(progress)
        clip_range_vf = self._get_clip_range_vf(progress)
        lr = self._get_lr(progress)

        # 手动更新学习率（不依赖 LambdaLR，避免 total_timesteps 未知的问题）
        for param_group in self.optimizer.param_groups:
            param_group["lr"] = lr

        # ---- 优势归一化（可选，整个 batch 做一次） ----
        if self.normalize_advantage:
            adv_flat = self.rollout_buffer.advantages[: self.rollout_buffer.pos].reshape(-1)
            adv_flat = (adv_flat - adv_flat.mean()) / (adv_flat.std() + 1e-8)
            self.rollout_buffer.advantages[: self.rollout_buffer.pos] = adv_flat.reshape(
                self.rollout_buffer.pos, self.n_envs
            )

        # 记录损失，用于日志
        entropy_losses, policy_losses, value_losses, approx_kl_divs = [], [], [], []
        continue_training = True

        # -------------------- 多 epoch 更新 --------------------
        for epoch in range(self.n_epochs):
            approx_kl_divs_epoch = []

            for rollout_data in self.rollout_buffer.get(self.batch_size):
                obs, actions, old_values, old_log_prob, advantages, returns = rollout_data

                # 重新评估当前策略下的 log_prob、熵、价值
                values, log_prob, entropy = self.policy.evaluate_actions(obs, actions)
                values = values.float()
                log_prob = log_prob.float()
                advantages = advantages.float()

                # ---- 策略损失（PPO-Clip） ----
                ratio = torch.exp(log_prob - old_log_prob)
                policy_loss_1 = advantages * ratio
                policy_loss_2 = advantages * torch.clamp(ratio, 1 - clip_range, 1 + clip_range)
                policy_loss = -torch.min(policy_loss_1, policy_loss_2).mean()

                # ---- 价值损失（可选 value clipping） ----
                if clip_range_vf is None:
                    value_loss = F.mse_loss(values, returns)
                else:
                    # SB3 风格：限制新 value 相对旧 value 的变化幅度，取 clip/不 clip 中较大者
                    values_clipped = old_values + torch.clamp(
                        values - old_values, -clip_range_vf, clip_range_vf
                    )
                    value_loss1 = F.mse_loss(returns, values)
                    value_loss2 = F.mse_loss(returns, values_clipped)
                    value_loss = torch.max(value_loss1, value_loss2)

                # ---- 熵奖励（鼓励探索） ----
                entropy_loss = -entropy.mean()

                # ---- 总损失与反向传播 ----
                loss = policy_loss + self.vf_coef * value_loss + self.ent_coef * entropy_loss

                self.optimizer.zero_grad()
                loss.backward()
                nn.utils.clip_grad_norm_(self.policy.parameters(), self.max_grad_norm)
                self.optimizer.step()

                # ---- 近似 KL，用于 early stopping ----
                with torch.no_grad():
                    log_ratio = log_prob - old_log_prob
                    approx_kl = torch.mean((torch.exp(log_ratio) - 1) - log_ratio).item()
                    approx_kl_divs_epoch.append(approx_kl)

                policy_losses.append(policy_loss.item())
                value_losses.append(value_loss.item())
                entropy_losses.append(entropy_loss.item())

            mean_epoch_kl = np.mean(approx_kl_divs_epoch)
            approx_kl_divs.append(mean_epoch_kl)

            # KL 超过阈值则提前结束所有 epoch
            if self.target_kl is not None and mean_epoch_kl > self.target_kl:
                if self.verbose > 0:
                    print(
                        f"  [early stop] epoch {epoch + 1}/{self.n_epochs}, "
                        f"KL={mean_epoch_kl:.5f} > target_kl={self.target_kl:.5f}"
                    )
                continue_training = False
                break

        self._n_updates += 1

        # -------------------- TensorBoard 日志 --------------------
        if self.writer is not None:
            self.writer.add_scalar("train/policy_loss", np.mean(policy_losses), self._n_updates)
            self.writer.add_scalar("train/value_loss", np.mean(value_losses), self._n_updates)
            self.writer.add_scalar("train/entropy_loss", np.mean(entropy_losses), self._n_updates)
            self.writer.add_scalar("train/approx_kl", np.mean(approx_kl_divs), self._n_updates)
            self.writer.add_scalar("train/clip_range", clip_range, self._n_updates)
            self.writer.add_scalar("train/lr", lr, self._n_updates)

    # -------------------- 主学习循环 --------------------
    def learn(self, total_timesteps: int, log_interval: int = 1):
        """
        主入口：反复收集 rollout -> 计算 GAE -> train()，直到达到 total_timesteps。
        """
        self._total_timesteps = total_timesteps
        self._start_time = time.time()

        # 初始化环境
        obs, _ = self.env.reset()
        self._last_obs = np.asarray(obs, dtype=np.float32).reshape(
            self.n_envs, *self.observation_space.shape
        )

        while self.num_timesteps < total_timesteps:
            # ---- 1. 收集 rollout ----
            last_values, last_dones = self.collect_rollouts(self.env, total_timesteps)

            if self.rollout_buffer.pos == 0:
                break

            # ---- 2. 计算 GAE 优势和回报 ----
            self.rollout_buffer.compute_returns_and_advantages(last_values, last_dones)

            # ---- 3. 更新策略 ----
            self.train()

            # ---- 4. 打印日志 ----
            if self.verbose > 0 and self._n_updates % log_interval == 0:
                elapsed = time.time() - self._start_time
                fps = int(self.num_timesteps / elapsed) if elapsed > 0 else 0
                mean_reward = (
                    np.mean(list(self.ep_info_buffer)) if len(self.ep_info_buffer) > 0 else -np.inf
                )
                print(
                    f"updates={self._n_updates:4d} | "
                    f"steps={self.num_timesteps:7d} | "
                    f"fps={fps:4d} | "
                    f"mean_reward(last100)={mean_reward:.2f}"
                )
                if self.writer is not None:
                    self.writer.add_scalar("rollout/ep_rew_mean", mean_reward, self.num_timesteps)

        if self.writer is not None:
            self.writer.close()

        return self

    # -------------------- 保存 / 加载 --------------------
    def save(self, path: str):
        """保存模型参数、优化器、观测归一化统计量和训练进度"""
        os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
        data = {
            "policy_state_dict": self.policy.state_dict(),
            "optimizer_state_dict": self.optimizer.state_dict(),
            "hyperparams": self._get_constructor_parameters(),
            "num_timesteps": self.num_timesteps,
            "_n_updates": self._n_updates,
        }
        if self.obs_rms is not None:
            data["obs_rms"] = {
                "mean": self.obs_rms.mean,
                "var": self.obs_rms.var,
                "count": self.obs_rms.count,
            }
        else:
            data["obs_rms"] = None

        torch.save(data, path)
        if self.verbose > 0:
            print(f"[save] {path}")

    @classmethod
    def load(cls, path: str, env: gym.Env, device: Union[torch.device, str] = "auto"):
        """
        从 save 文件恢复模型。需要传入新的 env（也可以把 env 存入 hyperparams 恢复）。
        """
        data = torch.load(path, map_location="cpu")
        hyperparams = data["hyperparams"]
        hyperparams["env"] = env
        hyperparams["device"] = device

        model = cls(**hyperparams)
        model.policy.load_state_dict(data["policy_state_dict"])
        model.optimizer.load_state_dict(data["optimizer_state_dict"])

        if data["obs_rms"] is not None:
            model.obs_rms.mean = data["obs_rms"]["mean"]
            model.obs_rms.var = data["obs_rms"]["var"]
            model.obs_rms.count = data["obs_rms"]["count"]

        model.num_timesteps = data.get("num_timesteps", 0)
        model._n_updates = data.get("_n_updates", 0)
        return model
