    数据运算 ¶

    • 0 可以单独使用，但不能作为前缀放在其他数字前面
    • Python 处理超大整数计算上不会出现任何错误
    • /执行的是浮点除法，即使运算对象都是整数，结果依然是浮点数 //执行整除。两个整数整除得到结果是整数，浮点数参与整除结果是浮点数
    • e代表 10 为底的幂，也就是科学计数法，e的前面不能为空，且必须是整数
    • j表示复数的虚部，使用complex.real得到实部，complex.imag得到虚部
    • *在实参前表示序列拆包，在形参前表接受不定长数目参数，元组存放，在赋值号左表接受不定长数目参数，列表存放

    • **放在形参前表收集不定长数目参数到字典中，放在字典前表字典拆包

    • 常用运算：

      • divmod(beichu, chu)，得到商和余数的元组，（商，元组）
      • round(x, n)，得到 x 的四舍五入值，n 是小数点位数
      • abs(x)，得到绝对值
      • complex(real, imag)，得到复数 real+imag*j

    序列 ¶

    • Python 内置的序列包括：

      • 列表list
      • 元组tuple
      • 字符串str
      • Unicode 字符串
      • buffer 对象
      • range 对象

    • 通用序列操作：

      • X1 + X2：连接两个序列，生成新序列
      • X * n：重复 n 次序列，生成新序列
      • X[i]：引用序列下标 i 的成员，如果下标是负数，从最后往前数，倒数第一个是 -1
      • X[i:j]：引用序列下标 i 到 j-1 的子序列，也可以用负数，要包括最后一个用[i:]，起点是 0，那么可以省略[:]
      • X[i:j:k]：引用序列下标 i 到 j-1 的子序列，步长为 k。k 可以取负数，要将整个序列逆过来，用[::-1]
        • 赋值运算X2 = X1不会产生新序列，两个变量指向同一个序列。如果其中一个变量改变了内容，另一个变量也进行了修改
        • 要复制一个新序列用X2 = X1[:]
      • len(X)：序列中成员个数
      • max(X)：序列中的最大值。如果序列内放的是字符串或序列是字符串，会按照 Unicode 的编码比较大小，min 同样
      • min(X)：序列中的最小值
      • v in X、v not in X：检查 v 在不在序列中，返回 bool 值
        • 对于列表，只能检查单个数据是否在序列中
        • 对于字符串，还可以检查一个字符串是否是另一个字符串的一部分

    函数 ¶

    • 函数定义：
      • def name(...):
      • lambda x1,x2...,xn : expression：lambda 表达式，不是语句而是表达式，定义了一个匿名函数。表达式返回了一个函数 
        g = lambda x,y,z: x+y+z
g(1,4,5) # g是个函数，结果是10
    • 函数参数 ( 形参 ):
      • 位置参数：按照传入顺序依次赋值给形参dis(1, 2)
      • 关键字参数：指定对应参数的名字，可以不按照定义顺序dis(x=1, y=2)
      • 位置参数与关键字参数可以混用，但要先写位置参数，再写关键字参数
      • 默认值参数：定义时给定默认值，如果不给实参，就按照默认值计算def dis(x, y=5)。默认值在函数定义时已经创建，并非运行时创建。默认值相同的函数调用使用同一个函数对象，默认值不同的函数调用创建新的函数对象
      • 不定长数目参数：参数数量不确定时，*将一组可变数量的位置参数变为一个元组存放def dis(x, *y)
      • *放在形参前表不定长数目参数，元组存放，放在实参前表序列拆包
      • **放在形参前表收集不定长数目参数到字典中，形参名字是键，形参对应值是值
      • 实参是不可变对象时，形参值改变不影响实参；实参是可变对象时，形参值改变可能影响实参。如传入列表，函数内改变列表，列表本身就会改变
    • 函数特性：
      • 函数是 Python 中的一种对象
      • 函数可以赋值给变量，所以一个函数可以有多个名称
      • 函数可以作为其他函数的参数
      • 函数可以嵌套
      • 函数的返回值可以是函数

    函数无return时，默认返回None，函数返回值可以是数字、列表等，还可以是函数

    命名空间和作用域 ¶

    变量查找顺序：局部命名空间 -> 全局命名空间 -> 内置命名空间

    • 类型：

      • 内置命名空间：Python 解释器启动时创建，记录所有标准常量名、标准函数名等
      • 全局命名空间：程序运行的命名空间，记录全局变量
      • 局部命名空间：程序中的函数的命名空间，记录函数内定义的变量

    • Python 特性：

      • 在函数中赋值全局变量，使用global关键字声明该变量为全局变量

    模块与包 ¶

    一个 Python 文件是一个模块，使用import引入，包是一个目录，包括许多模块和一个__init__.py文件

    • 模块使用：

      • 同一目录下可以直接引入，不同目录下可以用 sys 模块加入搜索路径后引入
      • import Module as name：as关键字给模块起别名
      • dir()：查看全局命名空间的变量和函数
      • dir(模块名)：查看模块的所有变量和函数
      • del 模块名：删除引入的模块

    • 模块特性：

      • 模块名一般是文件名，程序运行时变量__name__是模块名
      • 模块是主程序，__name__的值是__main__

    • 包特性：

      • __init__.py：可以是空文件，但必须有
      • import 包名.模块名.函数

    • sys 模块

      • sys 是 Python 自带模块，import sys引入，引入后sys.path变量所列目录就是模块搜索路径
      • sys.path：模块搜索路径的字符串列表。sys.path.append()可以增加查找路径
      • sys.argv：通过命令行给程序传递参数
      • sys.stdin、sys.stdout：重定向标准 I/O 流

    文件 ¶

    • 文件类型：

      • 二进制文件：图形文件、文字处理程序等计算机程序，有特殊的格式和计算机代码
      • 文本文件：可用文字处理程序阅读的简单文本文件

    • 常用操作：

      • open()：打开文件。fileobj = open(filename, mode, encoding=None)，mode 是指明文件类型和操作的字符串，第一个字母是操作，第二个是文件类型，encoding 是文件编码的名字
        • r：只读模式 ( 默认 )
        • w：覆盖写模式，不存在就新建，存在就重写
        • a：追加模式，存在就追加
        • +：与r/w/a/x一起用，增加读写功能
        • t：文本类型文件 ( 默认 )
        • b：二进制类型文件
      • f.read([size])：从打开的文件读取指定字节的内容，如果没有参数或参数为负，读取全部内容
      • f.readline()：读取一行内容
      • f.readlines()：读取所有行，返回列表
      • f.write(s)：字符串 s 的内容写入文件，默认使用 utf-8 编码
      • f.tell()：返回文件读写的当前位置
      • f.close()：关闭文件，关闭后不能再读写

    异常处理 ¶

    主要使用 try-except 进行异常处理，存在错误就会抛出异常，然后执行 except，否则跳过 except 块，无论是否发生异常都会执行 finally 块

    try:
    pass
except 异常1 as name:
    pass
except 异常2:
    pass
else: 
    pass
finally:
    pass

    发生异常时会自动进入到相应异常的处理块，except 是可选项，如果不提供会由 Python 默认处理，即终止程序并打印提示信息。而如果 try 中没有异常，会执行 else 块

    • 常见异常：

      • Exception：用于 except 捕捉异常，常放在最后捕捉前面未处理的所有异常
      • KeyboardInterrupt：用户终端执行
      • ImportError：导入模块 / 对象失败，常为路径错误
      • IndexError：序列中没有此索引
      • RuntimeError：一般的运行时错误
      • AttributeError：对象没有这个属性
      • OSError：操作系统错误，如打开一个不存在的文件
      • KeyError：映射中没有此键
      • TypeError：对类型无效的操作
      • ValueError：传入无效参数

    • 常用操作 :

      • raise expression：自定义异常，处理可能出现的特殊情况。表达式可以是异常名，可以是函数调用模式Exception("异常情况")
      • assert expression[, expression2]：表达式是 False 时触发AssertionError异常，表达式 2 是异常情况的字符串。系统变量__debug__为 True 时可以用来配合调试

    迭代器和生成器 ¶

    • 迭代器：

      • 迭代器是一个表示数据流的对象，每次只返回一个元素
      • Python 要求迭代器必须有__next__()方法，该方法不接受参数，总是返回数据流的下一个元素。如果数据流没有元素，返回StopIteration异常
      • 迭代器不一定是有限的
      • 自定义迭代器： 
        class IteName(object):
    def __init__(self,):
        pass
    def __next__(self,):
        pass
ite = iter(IteName())
for i in ite:
    pass
        • 可迭代对象是可以用 for 循环生成值序列的任何对象
        • 内置函数iter()接受任意对象，并返回可迭代对象来输出其内容或元素
        • iter(object[, sentinel])：第一个参数是支持迭代协议 ( 有__iter__()方法 ) 的集合对象或可调用的对象，第二个是触发StopIteration异常的条件，__next__()取得的值等于该参数，触发异常并终止循环

    • 生成器：

      • 生成器是一类用来简化编写迭代器工作的特殊函数，也称生成器函数，返回一个产生数据流的迭代器
      • 生成器在退出一个函数时不扔掉局部变量，而且可以在退出函数的地方重新恢复运行，可以被看作可恢复的函数
      • yield语句仅在定义生成器时使用，且仅被用于生成器函数的函数体内部。要定义生成器函数也就是返回使用yield语句
      • yield expression、递归用法yield from 生成器(函数)
      • 惰性计算：生成器一次只生成一个对象，而不是一次生成全部对象再返回。一般用于处理大数据量的文件，能显著提高内存利用率
      • 生成器可以用于逐渐产生结果的复杂递归算法，只要在递归调用的部分使用yield即可

    装饰器和上下文管理器 ¶

    • 嵌套函数 / 内部函数：函数中定义函数

      • 外部嵌套函数命名空间：对嵌套函数内定义的函数来说，嵌套函数的局部命名空间即外部嵌套函数命名空间
      • 标识符查找顺序：局部命名空间 -> 外部嵌套函数命名空间 -> 全局命名空间 -> 内置模块命名空间
      • global函数中引用全局命名空间的变量，nonlocal函数引用外部嵌套函数命名空间的变量。都会修改引用的变量

    • 装饰器

      • 装饰器是简写的嵌套函数，可以在不修改函数代码的情况下，给函数增加新功能
      • 自定义装饰器： 
        def deco(func):
    def wrapper(*args, **argv):
        return func(*args, **argv)
    return wrapper
@deco
def Name()
    pass
        • @deco的作用等价于Name = deco(Name)
        • 装饰器函数的形参一般是函数，实参是被装饰函数的名字
        • 装饰器函数中要嵌套定义另一个函数，其中*args为 0 个或多个位置参数，**argv为 0 个或多个关键字参数，一般用来传递被装饰函数的实参
        • 一个函数可以用多个装饰器函数装饰，先执行靠近被装饰函数的装饰器，再执行上面的装饰器

    • 上下文管理器

      • 上下文管理器是一个对象，定义了执行with语句时建立的上下文环境
      • 上下文管理器用于规定某个对象的使用范围，一旦进入或离开该使用范围，会有__enter()__或__exit()__方法调用。一般用于保存、恢复各种全局状态，锁定和解锁资源，关闭打开文件等
      • 使用 : 
        with expression as 变量:
    pass
with expression:
    pass
      • 自定义上下文管理器： 
        from contextlib import contextmanager
@contextmanager
def write_file(file_name):
    try:
        fread = open(file_name, "w")
        yield fread
    finally:
        fread.close()
with write_file("Name.txt") as f:
    f.write("Hello World!")
        • 内置模块contextlib可以将一个对象变为上下文管理器
        • 自定义的上下文管理器必须返回一个生成器，yield的结果会用在with语句中

    异步编程 ¶

    • 异步编程

      • 异步编程时一种处理缓慢且不可预测资源的有效方式，能同时高效地处理多种资源
      • 异步方式是执行某个任务处于等待状态时，CPU 不等待而是执行下一个任务
      • 异步编程有三种方式：协程、线程、进程

    • 协程

      • 协程：调用异步函数时创建的对象就是协程
      • 一个线程可以包含多个协程。协程不是线程不是进程，是一个特殊的函数，这个函数可以在某个地方挂起，并且可以重新在挂起处继续运行
      • 一个线程内多个协程执行是串行的，多个协程的执行切换由程序决定，通过一个协程sleep()来切换到别的协程
      • await关键字：
        • await将异步函数的控制权交给事件循环对象，并挂起当前协程的执行
        • await只能用在异步函数内部，不能在普通函数中用
        • await后必须是可等待对象，可等待对象有协程、任务
        • await后是协程函数时，必须等协程函数返回
      • asyncio( 异步编程的标准模块 ):
        • task = asyncio.create_task(func())：函数创建的任务负责在事件循环对象中执行协程
        • asyncio.gather()：创建任务，参数是协程，能将协程作为任务异步执行
        • asyncio.run()：启动异步程序执行，参数是协程，只能被调用一次。函数总是创建一个新的事件循环对象并在结束时关闭
      • 异步编程： 
        import asyncio
async def func1():
    await asyncio.sleep(1)
async def func2():
    await asyncio.sleep(1)

async def main():
    await asyncio.gather(func1(), func2())
asyncio.run(main())

    math 库 ¶

    import math
    • 常用操作：
      • math.e：自然常数
      • math.pi：圆周率
      • math.log(x[.base])：x 的以 base 为底的对数，base 默认为 e
      • math.pow(x, y)：x 的 y 次方
      • math.sqrt(x)：x 的平方根
      • math.ceil(x)：不小于 x 的最小整数
      • math.floor(x)：不大于 x 的最大整数
      • math.sin(x)、math.cos(x)、math.tan(x)：三角函数，注意 x 是弧度表示

    random 库 ¶

    import random
    • 常用操作：
      • random.random()：范围 [0.0, 1.0) 的随机浮点数
      • random.uniform(a, b)：范围 [a, b] 的随机浮点数
      • random.randint(a, b)：范围 [a, b] 的随机整数
      • random.shuffle(x)：将列表 x 内的元素随机排列
      • random.sample(X, k)：从序列 X 中随机采样长度为 k 的序列，并随机排序
      • random.send(n)：对随机数生成器初始化，n 是随机种子。默认随机种子是系统时间

    内置函数 ¶

    • 内置转换函数：

      • bool()：根据传入内容创建一个新 bool 值。0、空字符串、空序列、无传入参数对应False
      • int(x[, base])：根据传入内容创建一个新整数。无传入参数对应 0，浮点数取整，可以把字符串转为数字，base 是进制
      • float()：根据传入内容创建一个新浮点数。无传入参数对应 0.0
      • complex()：根据传入内容创建一个新复数。无传入参数对应0j，字符串、(real, imag)对应相应复数
      • str()：创建一个字符串。无传入参数对应空字符串，传入None对应"None"
      • list()：根据传入内容创建一个新列表。无传入参数对应空列表，字符串对应每个字符组成的列表

    • abs()

    • enumerate()
    • hasattr()
    • isinstance(obj, class)：检查对象是否为类的一个实例
    • len()
    • map(function, iterable...)：根据函数对可迭代对象映射，返回新的可迭代对象。函数要作用于可迭代对象的每一个元素，返回 function 返回值组成的可迭代对象
    • max()、min()
    • all()、any()：参数是可迭代对象，all()都是 True 才返回 True，any()只要有一个 True 就返回 True
    • pow()
    • reversed()
    • sorted(iterable[, key[, reverse]])：对字符串、列表、元组、字典等排序。sort是列表独有的排序方法，直接修改列表，sorted可以排序更多数据类型，产生新列表。key是比较的函数，函数参数取自可迭代对象，reverse是排序规则，=True是降序，=False是升序 ( 默认 )

    • zip([iterable,...])：将可迭代对象中对应的元素打包成元组，返回元组组成的可迭代对象。参数是一个或多个序列，如果各个可迭代对象的长度不一样，返回对象与长度最短的一致。常用于创建字典

    • type(x)：查询对象的类型，返回值是对象的类型

    • range(start, stop, step)：返回特定区间的自然数序列。[start, stop)，start 默认为 0，step 是步长，默认为 1
    • sum()：求列表和
