    正则表达式 ¶

    • 普通字符不变，包括字母、数字

    • 特殊字符 :

      • . 匹配任意 单个 字符，换行符除外
      • * 匹配前面的字符零次或多次
      • + 匹配前面的字符一次或多次
      • ? 匹配前面的字符零次或一次
      • \d 匹配任意一个数字，和[0-9]一样。\D 匹配非数字
      • \w 匹配任意一个单词 ( 字母、数组、下划线 )，和[a-zA-Z0-9]一样。\W 匹配非单词
      • \s 匹配任意一个空白字符 ( 空格、制表符 )。\S 匹配非空白
      • ^ 从字符串开头进行匹配，或者排除指定字符 ( 取反必须放在开头，放在之后表示一个普通字符 )。$ 从字符串结尾进行匹配
      • {m,n} 匹配前面的字符 m 到 n 次。
        • 缺失的情况下会设定为默认值，缺失 m 为最少重复 0 次，缺失 n 为最多重复无限次。
        • {m} 完全匹配 m 次，等同于{m,m}
      • | 或操作，前后只要有一个匹配即可

      特别说明，\加在一些特殊符号前表示转义，如\.意思是字符串的.，不是匹配任意单个字符

      特别说明，上面提到匹配前面的字符指的是前面的一个字符，如果使用分组，整个分组视为一个字符

    • 字符集

      • 用于匹配一组字符中的任意一个，加[]表示
      • [X-Y] 表示从 X 到 Y 的所有字符构成的字符集，包括 X 和 Y，X/Y 可以是字母或数字
      • [^XY] 表示非 X、非 Y 的字符集，X/Y 可以是字母或数字

    • 分组

      用于将多个字符组合在一起，作为整体进行操作，加()表示

      分组可以嵌套

    • r前缀

      表示原始字符串，不用考虑转义。\就是字符串，而非转义符

      反斜杠不以任何特殊的方式处理前缀为 'r' 的字符串字面

    re 库常用函数 ¶

    • re.compile(pattern)

      • 功能 : 预编译正则表达式，提升性能
      • re 使用正则表达式的步骤：
        • 编译正则表达式，同时检查正则表达式的字符串合法
        • 用编译后的正则表达式去匹配字符串
      • compile 编译后生成 Regular Expression 对象，它自己包含了正则表达式，所以后续调用方法时不用给出正则字符串

    • re.search(pattern, string)

      • 功能 : 搜索字符串中第一个匹配项
      • 返回 : 匹配成功返回 match 对象，否则返回 None
      • 说明 : 如果开头不匹配，中间匹配，search 可以匹配

    • re.match(pattern, string)

      • 功能 : 从字符串 string 开头匹配 pattern 模式
      • 返回 : 匹配成功返回 match 对象，否则返回 None
      • 说明 : 如果开头不匹配，中间匹配，match 无法匹配

    • re.fullmatch(pattern, string)

      • 功能 : 完全匹配整个字符串

    • re.findall(pattern, string)

      • 功能 : 找到所有匹配到的字符串
      • 返回 : 以列表类型返回所有匹配到的子串

    • re.finditer(pattern, string)

      • 功能 : 返回匹配结果的迭代器，含位置信息
      • 返回 : 返回一个匹配结果的迭代类型，这个迭代类型是 match 对象

    • re.sub(pattern, repl, string)

      • 功能 : 寻找 pattern 匹配项，使用 repl 替换
      • 返回 : 返回替换后的字符串

    • re.split(pattern, string)

      • 功能 : 按匹配项分割字符串，返回的结果中不包含匹配项
      • 返回 : 以列表返回

    • re.escape()

      • 功能 : 转义特殊字符

    • re.purge()

      • 功能 : 清除缓存

    匹配对象 /match 的方法 / 属性 ¶

    • group()

      • 默认group() : 返回所有匹配到的字符串，以元组返回，其中每个元素都是匹配到的一组字符串
      • group(0): 返回与整个正则表达式相匹配的字符串
      • group(n): 返回第 n 个匹配到的子串，以元组返回
      • group(n1,n2,...): 返回第 n1，n2 等等个匹配到的字符串

    • groups()

      • 功能 : 返回所有匹配字符串的元组

    • start()/end()

      • 功能 : 匹配的起始 / 结束位置

    • span()

      • 功能 : 返回匹配范围，(start, end)

    match 可以用if m来直接判断是否匹配成功

    贪婪匹配 ¶

    正则匹配默认是贪婪匹配，也就是匹配尽可能多的字符，比如，\d+会匹配所有的数字

    在遇到特定格式的匹配时 ( 比如无明显分隔符的时候 ) 可能会出错，\d+?可以使用非贪婪匹配，也就是尽可能少匹配。 这里的少匹配是什么意思呢? 

    # 贪婪
re.match(r'^(\d+)(0*)$', '102300').groups()
>> ('102300', '')
# 非贪婪
re.match(r'^(\d+?)(0*)$', '102300').groups()
>> ('1023', '00')

    少匹配就是让下一个正则项能尽可能多匹配
