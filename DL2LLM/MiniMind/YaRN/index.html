    长度外推 ¶

    针对问题 : 突破训练长度限制 (Length Extrapolation)，支持更长文本

    本文的长度外推技术都基于 RoPE

    外推问题 :

    当 \(m > L_{train}\) 时，\(\cos(m \theta_i)\) 会出现训练时从未见过的数值分布，导致注意力机制崩塌 (PPL 爆炸 )

    RoPE 中，Query 或 Key 向量的第 i 组分量 (\(i \in [0, \frac{d}{2})\))，位置为 m，基础频率为 \(\theta_i\)，训练最大长度为 \(L_{train}\)，推理 / 目标最大长度为 \(L_{new}\)

    PPL(Perplexity)：困惑度，是衡量语言模型预测能力的指标。PPL 越低，模型预测下一个词的能力越强。数学上，PPL 是交叉熵损失的指数形式，公式 :

    \[PPL = \exp(-\frac{1}{N} \sum_{i=1}^{N} \log P(w_i | w_{<i})) \]

    其中 \(N\) 是词的数量，\(P(w_i | w_{<i})\) 是模型预测第 \(i\) 个词的概率。PPL 可以理解为模型在预测时的平均分支数，PPL 越高，模型越不确定

    外推技术 ¶

    • PI(Position Interpolation，线性插值 )

      • 核心思想 : 将新的长位置 \(L_{new}\) 调整到 \([0, L_{train}]\) 内

      • 公式 :

        \[m^{\prime} = \frac{m}{s}\]
        \[Angle = \frac{m}{s} \theta_i\]
      scale = L_new / L_train  # 例如 4096->8192, scale=2
t = torch.arange(L_new)
t = t / scale  # 将 0~8191 压缩回 0~4095.5
freqs = torch.outer(t, inv_freq)

      • 优点 : 极其简单，微调几百步就能让模型适应长文本

      • 缺点 :

        • 高频分辨率丢失

        对于高频部分 (i 小 )，相邻 token 的旋转角差值变小了，模型无法精确区分相邻的词，分辨率 (Resolution) 降低

    • NTK-Aware Interpolation

      • 核心思想 : 根据 Neural Tangent Kernel(NTK) 理论，高频特征学习快，低频特征学习慢。不改变位置 m，可以保持分辨率；而改变“基数”b，可以让高频部分保持不变 ( 不插值 )，只对低频部分进行插值

      • 数学原理 : 找一个新的基数 \(b^{\prime}\)，使最低频 (\(i=d/2-1\)) 的效果等同于 PI 插值，高频变化最小

      \[ PI: \frac{m}{s} \cdot b^{-2i/d} \\ NTK-Aware: m \cdot (b^{\prime})^{-2i/d} \]

      由于要在最低频相等，近似可得

      \[b^{\prime} = b \cdot s\]

      考虑到实际的所有维度，实际修正为

      \[b^{\prime} = b \cdot s^{\frac{d}{d-2}}\]
      # 不用修改位置m，只修改频率的base
alpha = L_new / L_train
# 计算新的频率
new_base = 10000 * (alpha ** (dim / (dim - 2)))
inv_freq = 1.0 / (new_base ** (torch.arange(0, dim, 2) / dim))
# 生成 cos/sin 表
      • 优点 : 解决了 PI 在高频部分分辨率丢失的问题，无需微调也能获得比 PI 更好的 PPL，微调后效果更佳

    • Dynamic NTK Interpolation

      • 核心思想 : 前两种方法的 \(s\) 是固定的，推理的最大长度和实际长度相差较大时 ( 实际长度仍在训练最大长度内 )，模型也会进行压缩，性能下降。而 Dynamic NTK 根据当前的序列长度动态计算 \(S\)

      • 计算流程 :

        • 每一步推理或者每隔一段计算，获取当前序列长度 \(L_{curr}\)
        • 如果 \(L_{curr} \leq L_{train}\)，获取原始 RoPE(scale=1)
        • 如果 \(L_{curr} > L_{train}\)，计算 scale，\(s=L_{curr} / L_{train}\)
        • 使用 NTK-Aware 重新计算 \(b^{\prime}\) 和频率表

      • 关于实现 :

        • RoPE 是静态的，通常在 Attention 前完成，如果要动态计算，KV Cache 的 K 向量是基于旧的 \(s\) 选择的，\(s\) 变化后也应该变化
        • 实际上，为了性能考虑，Dynamic NTK 通常不重算 KV Cache，会有一定的误差，但模型可以容忍这种渐变。或者也可以采用不旋转存 KV，取出时旋转的方法，但是计算量增大

      • 优点 : 在短文本上保持原始性能，随着长度增加平滑过渡到外推模式

    • NTK-by-parts Interpolation/ 分段 NTK

      • 核心思想 : NTK-Aware 对高频部分仍有影响，NTK-by-parts 提出波长 (Wavelength，\(\lambda = 2\pi / \theta_i\))

        • 如果波长很短，远小于训练长度，表示高频，局部信息，不进行插值，保持原始 RoPE
        • 如果波长很长，大于训练长度，表示低频，长距离信息，必须插值
        • 中间部分，接近于训练长度，过渡？？？

      • 数学原理 :

        波长 \(\lambda_i = 2\pi \cdot b^{2i/d}\)，两个阈值 \(\alpha,\beta\)，对于每个维度 i

        • \(\lambda_i / L_{train} < \alpha\)，不插值
        • \(\lambda_i / L_{train} > \beta\)，全量插值
        • \(\alpha < \lambda_i / L_{train} < \beta\)，线性混合

        直接对 \(m\) 混合比较麻烦，通常改变频率 \(\theta_i\)

        \[\theta_i^{\prime} = (1-\gamma_i)\theta_i + \gamma_i \cdot \frac{\theta_i}{s} \]

        其中 \(\gamma_i\) 为根据波长计算得到的 \(ramp\) 函数，范围在 0 到 1 之间

      # 计算每个维度的波长，为每个维度i计算一个缩放因子
wavelen = 2 * math.pi / inv_freq
# 这种方法不改 base，而是直接改 freq
# 对 wavelen 小的不变，大的除以 scale

    • YaRN(Yet another RoPE extension)

      • 核心思想 : 结合 NTK-by-parts 的分段思想，并解决了一个隐藏问题：熵 (Entropy) 的变化。将所有 token 的 RoPE 距离拉开 ( 或压缩 ) 时，Attention 矩阵中的点积数值分布会发生变化 ( 通常变得更“平”或更“尖”)，导致 Softmax 后的分布熵变大，模型困惑度增加。 YaRN 引入 temperature scaling 来修正注意力分布

      • 数学原理 :

        • NTK-by-parts
          • 使用分段策略，高频不旋转，低频旋转，中间插值
          • 不修改 base，直接修改频率 \(\theta\)

        • Length Scaling( 注意力修正 )

          • 计算 Attention Score 时乘上因子 \(\sqrt{t}\)，或者在 RoPE 后，Q/K 乘上 \(\sqrt{\sqrt{t}}\)
          \[ \sqrt{t} \approxeq 0.1 \ln(s) + 1 \]
          • 不加这个修正，长文本外推时，注意力分布会因为上下文变长而变得过于“平坦”，模型不知道该关注谁
      # Get_Rotary_Embedding: 生成修改后的 cos/sin 表（基于分段逻辑）
# Model Forward: 在应用 FlashAttention 之前或之后，对 Logits 进行 scaling，或者直接对 RoPE 后的 output 进行 scaling

# 1. 计算 ramp function (ramp) 基于波长
# 2. inv_freq_new = inv_freq * (1 - ramp) + (inv_freq / scale) * ramp
# 3. 还有一个 scale factor
sqrt_t = 0.1 * math.log(scale) + 1
# 在应用 RoPE 后，将 q, k 乘以 sqrt(sqrt_t) (或者在 attention socre 乘 1/t)
q = apply_rope(q, inv_freq_new) * t_correction
k = apply_rope(k, inv_freq_new) * t_correction
      方法 核心思想 m( 位置 ) \(\theta\)( 频率 / 基数 ) x
      RoPE 旋转表示位置 不变 b=10000 不变
      PI 线性压缩位置 m -> m/s 不变 不变
      NTK-Aware 拉伸基数 不变 \(b->b\cdot s^{\frac{d}{d-2}}\) 不变
      Dynamic NTK 动态拉伸 不变 b 动态变化 不变
      NTK-by-parts 分频段处理 混合 高频不变，低频插值 不变
      YaRN 分段 + 修改熵 混合 高频不变，低频插值 乘上 \(\sqrt{t}\)
